# 设置页 23 tab 逐项验收（2026-10-29 · 对标计划收口）

口径：release 构建的真实窗口（CDP），用 App 自己的 `#settings` 入口打开，逐个 tab 点开、量、截图。
数据：`readings.json`（每个 tab 的标题字号、行式设置条数、控件右缘偏差、横向溢出）。

## 总览

| 指标 | 结果 |
|---|---|
| tab 数 | **23 / 23 全部点得开**（无报错、无空白页） |
| 横向溢出（`scrollWidth > clientWidth`） | **0 个 tab** |
| 标题字号（有 section-title 的 tab） | **13px / 620**，一致 |
| 标准行式设置（`.settings-rows > .setting-group`，label + 单控件） | **控件右缘偏差 = 0px，全部对齐** |
| 非零偏差 | **只出现在嵌套卡片 / 自定义块**，逐条说明见下表 |

## 非零偏差逐条判定（都不是错位）

| tab | 控件 | 偏差 | 结论 |
|---|---|---|---|
| 通用 | `模型` 行的 `select`（101px） | 99.4px | 该行是 `LABEL + .sp-row`（**模型选择 + 刷新/管理按钮**的组合行），不是标准 200px 列 ⇒ 设计如此 |
| 通用 | `我的标志` 文本框 | 210px | 身份块（`--identity-options`）多列布局，设计如此 |
| 通用 | `Base URL` / 852px 宽输入框 | 12px | 在 `provider-group` 卡片内（卡片自身 12px 内边距）⇒ 12px 是卡片内缩，不是错位 |
| 外观 | `字体粗细 (wght)` range（154px） | 46px | 该行是「滑杆 + 数值」自定义布局 |
| 安全 | `工具名 (支持 * 通配)` 文本框（357px） | 508px | 自定义块（左对齐的多行输入区），设计如此 |

## 结论

对标计划里 Phase 4 的验收口径是「**行式设置**的控件右缘误差 ≤2px」，这条**满足**（标准行全部 0px）。
非零偏差全部来自复合行/嵌套卡片/自定义块，属于有意的布局差异，不改 —— 强行套 200px 会截断模型名、锁死身份块多列。
