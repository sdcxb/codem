# 设置页逐 tab 验收（2026-10-28 · Phase D）

口径：release 构建的真实窗口（CDP），用 App 自己的 `#settings` 入口打开设置，
逐个点 tab，截图并读 DOM 计算值（`readings.json` 里有每张图的读数）。

## 结论

- 卡片标题现在是 **13px / 620**（`--fs-base` + `--weight-bold`）。
- **这轮截图抓到一个真缺陷**：改动前标题渲染成 **12px**——因为我第一版用了 `--fs-sm`，
  而它在本仓是 12px（`--fs-base` 才是 13px）。这条只有真机读数能发现（CSS 判据当时"绿"，
  因为它断言的就是 `--fs-sm`）。已改成 `--fs-base`，判据 `PHASE-D-1` 同步改成断言 13px 档。
- `外观` / `工具` / `记忆体检` 三个 tab 没有 `.settings-section-title`（结构不同，用卡片/分组标题），
  所以读数为 null —— 不是缺陷。
