# 14 读书动作（可选，看书/翻页）

**用途**：角色在阅览大厅查资料时播放。
**怎么用**：先把该角色的立绘作为**参考图**上传，再粘贴下面的提示词。
**生成后存成**：`C:\mimo-gui\.art-inbox\读书-队长.png`
**比例**：横版 3:1（一排 6 个姿势）

---

## 中文版（即梦 / 豆包 / Seedream 等）

```
参考我上传的角色图片，画同一个角色在读书的动画，Q 版像素画风格，16 位游戏美术，
粗黑描边，像素边缘干净锐利，不要抗锯齿。

一排 6 个姿势，从左到右是一个循环：低头看书、翻页、再低头看……
6 个姿势大小完全一致、脚底在同一条水平线上、彼此间距均匀。
角色双手捧着一本书，头微微低着，表情安静专注。

背景：纯品红色 #ff00ff，不要地面、不要投影。
不要：文字、水印、logo、光晕、模糊、多个不同角色。
```

## 英文版（Midjourney / DALL·E / GPT-Image 等）

```
using my uploaded character as reference, draw the same character reading a book,
chibi pixel art, 16-bit game style, thick dark outline,
crisp clean pixel edges, no anti-aliasing.

one horizontal row of 6 poses forming a loop: look down at book, turn the page, look down again...
all 6 poses exactly the same size, feet on the same horizontal line, evenly spaced,
character holding a book with both hands, head slightly lowered, quiet focused expression.

background: solid magenta #ff00ff, no ground, no shadow.
NO text, NO watermark, NO logo, NO glow, NO blur, NO different characters.
--ar 3:1 --style raw
```
