# 01 图书馆场景（最重要，先画这个）

**画什么**：一张俯视角的像素画图书馆地图，12 个房间，房间空着不放人。
**生成后存成**：`C:\mimo-gui\.art-inbox\场景.png`
**比例**：横版 16:9

---

## 中文版（即梦 / 豆包 / Seedream 等）

```
俯视 2.5D 像素画风格的温馨图书馆室内地图，16 位游戏美术，正交顶视角（能看到墙面正立面），
不要透视畸变，横版 16:9。

左侧是带长木桌和书架的大阅览厅；顶部中间是编目室（卡片柜、书架）；
右上角是小型代码实验室（桌子、电脑显示器）；右侧是档案室（档案柜）；
右中是机房（服务器机架）；下方中间是会议厅（圆桌）；
左下是写作工坊（书桌、纸张）；中央是带柜台的前台；右下是休息区（沙发、绿植）。

暖木色加米纸配色，粗黑描边，像素边缘干净锐利，不要抗锯齿；
房间空着，不要人物、不要文字、不要界面、不要水印；
平光，不要夸张阴影，不要光晕和模糊。
```

---

**画完之后（两种都行）**：

1. **自己换**（推荐，最快）：打开插件 → 设置 → 「场景图片」→ 选这张图（或直接拖到场景上），立刻生效。
2. **丢给我**：存成 `C:\mimo-gui\.art-inbox\场景.png`，跟我说一声，我把它做成内置预设。

比例不用管，插件会自动缩放；但如果能出 **16:9 横版**最好（例：2752×1536），拉伸最少。

> 换图只换画面，角色站位与岗位位置用的是固定布局。若图里的房间和参考框有偏差，
> 打开设置里的「在场景里显示对位参考线」，再用「画面微调」把图挪到对齐即可。
