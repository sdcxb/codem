# 16 出错动作（可选，报错/冒汗）

**用途**：角色执行失败或出错时播放。
**怎么用**：先把该角色的立绘作为**参考图**上传，再粘贴下面的提示词。
**生成后存成**：`C:\mimo-gui\.art-inbox\出错-队长.png`
**比例**：横版 3:1（一排 6 个姿势）

---

## 中文版（即梦 / 豆包 / Seedream 等）

```
参考我上传的角色图片，画同一个角色出错、慌张的动画，Q 版像素画风格，16 位游戏美术，
粗黑描边，像素边缘干净锐利，不要抗锯齿。

一排 6 个姿势，从左到右是一个循环：瞪大眼睛、头上冒汗、手足无措地挥手、再冒汗……
6 个姿势大小完全一致、脚底在同一条水平线上、彼此间距均匀。
角色表情慌张但不恐怖，头顶有小汗珠。

背景：纯品红色 #ff00ff，不要地面、不要投影。
不要：文字、水印、logo、光晕、模糊、多个不同角色。
```

## 英文版（Midjourney / DALL·E / GPT-Image 等）

```
using my uploaded character as reference, draw the same character panicking about an error,
chibi pixel art, 16-bit game style, thick dark outline,
crisp clean pixel edges, no anti-aliasing.

one horizontal row of 6 poses forming a loop: eyes wide open, sweat drop appearing,
flailing hands helplessly, more sweat...
all 6 poses exactly the same size, feet on the same horizontal line, evenly spaced,
panicked but cute expression, small sweat drops above the head.

background: solid magenta #ff00ff, no ground, no shadow.
NO text, NO watermark, NO logo, NO glow, NO blur, NO different characters.
--ar 3:1 --style raw
```
