# 07 档案员（档案室）

**画什么**：推着小推车的乌龟档案员
**生成后存成**：`C:\mimo-gui\.art-inbox\档案员.png`
**比例**：正方形 1:1

---

## 中文版（即梦 / 豆包 / Seedream 等）

```
Q 版像素画风格角色立绘，16 位游戏美术，粗黑描边，像素边缘干净锐利，不要抗锯齿，正方形 1:1。

角色：一只戴着小圆帽的乌龟档案员，双手扶着一个小推车（车上有文件盒），表情慢条斯理，
全身正面站立，面朝镜头。
角色占画面高度约 70%，水平居中，脚底靠近画面底部。
配色：青色马甲 + 棕色龟壳 + 米色手套。

背景：纯品红色 #ff00ff，画面里不要出现其他任何东西。
不要：文字、水印、logo、地面、投影、光晕、模糊、多个角色。
```
