# 15 睡觉动作（可选，打瞌睡）

**用途**：角色空闲/休眠时播放。
**怎么用**：先把该角色的立绘作为**参考图**上传，再粘贴下面的提示词。
**生成后存成**：`C:\mimo-gui\.art-inbox\睡觉-队长.png`
**比例**：横版 3:1（一排 6 个姿势）

---

## 中文版（即梦 / 豆包 / Seedream 等）

```
参考我上传的角色图片，画同一个角色打瞌睡的动画，Q 版像素画风格，16 位游戏美术，
粗黑描边，像素边缘干净锐利，不要抗锯齿。

一排 6 个姿势，从左到右是一个循环：闭眼、点头、快睡着、惊醒一下、再闭眼……
6 个姿势大小完全一致、脚底在同一条水平线上、彼此间距均匀。
角色站着打盹，头一点一点，头顶飘着小小的睡觉符号。

背景：纯品红色 #ff00ff，不要地面、不要投影。
不要：文字、水印、logo、光晕、模糊、多个不同角色。
```

## 英文版（Midjourney / DALL·E / GPT-Image 等）

```
using my uploaded character as reference, draw the same character dozing off,
chibi pixel art, 16-bit game style, thick dark outline,
crisp clean pixel edges, no anti-aliasing.

one horizontal row of 6 poses forming a loop: eyes closed, head nodding, almost asleep,
briefly startled awake, eyes closing again...
all 6 poses exactly the same size, feet on the same horizontal line, evenly spaced,
standing while napping, head bobbing, tiny sleep symbols floating above the head.

background: solid magenta #ff00ff, no ground, no shadow.
NO text, NO watermark, NO logo, NO glow, NO blur, NO different characters.
--ar 3:1 --style raw
```
