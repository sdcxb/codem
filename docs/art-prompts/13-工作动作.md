# 13 工作动作（可选，敲键盘/写字）

**用途**：角色在岗位"干活"时播放的动画。
**怎么用**：先把该角色的立绘作为**参考图**上传，再粘贴下面的提示词。
**生成后存成**：`C:\mimo-gui\.art-inbox\工作-队长.png`
**比例**：横版 3:1（一排 6 个姿势）

---

## 中文版（即梦 / 豆包 / Seedream 等）

```
参考我上传的角色图片，画同一个角色在工作（敲键盘、写东西）的动画，
Q 版像素画风格，16 位游戏美术，粗黑描边，像素边缘干净锐利，不要抗锯齿。

一排 6 个姿势，从左到右是一个循环：双手抬起、敲下、抬起、敲下……
6 个姿势大小完全一致、脚底在同一条水平线上、彼此间距均匀。
角色低头看着桌面，手在身前有节奏地动作，专注认真。

背景：纯品红色 #ff00ff，不要桌面、不要地面、不要投影。
不要：文字、水印、logo、光晕、模糊、多个不同角色。
```

## 英文版（Midjourney / DALL·E / GPT-Image 等）

```
using my uploaded character as reference, draw the same character working
(typing on a keyboard / writing), chibi pixel art, 16-bit game style,
thick dark outline, crisp clean pixel edges, no anti-aliasing.

one horizontal row of 6 poses forming a loop: hands up, hands down, hands up, hands down...
all 6 poses exactly the same size, feet on the same horizontal line, evenly spaced,
character looking down at the desk, hands moving rhythmically in front, focused.

background: solid magenta #ff00ff, no desk, no ground, no shadow.
NO text, NO watermark, NO logo, NO glow, NO blur, NO different characters.
--ar 3:1 --style raw
```
