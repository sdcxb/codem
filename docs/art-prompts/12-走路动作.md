# 12 走路动作（可选，给某个角色加行走动画）

**用途**：让角色在图书馆里走起来。不做也能用（我会用站立帧做简单的上下浮动）。
**怎么用**：先把该角色的立绘（比如 `队长.png`）作为**参考图**上传，再粘贴下面的提示词。
**生成后存成**：`C:\mimo-gui\.art-inbox\走路-队长.png`
**比例**：横版 3:1（一排 6 个姿势）

---

## 中文版（即梦 / 豆包 / Seedream 等）

```
参考我上传的角色图片，画同一个角色的走路动画，Q 版像素画风格，16 位游戏美术，
粗黑描边，像素边缘干净锐利，不要抗锯齿。

一排 6 个姿势，从左到右是完整的走路循环：抬左脚、落地、抬右脚、落地……
6 个姿势大小完全一致、脚底在同一条水平线上、彼此间距均匀。
每个姿势都是全身正面或四分之三侧面朝向，动作自然可爱。

背景：纯品红色 #ff00ff，不要地面、不要投影。
不要：文字、水印、logo、光晕、模糊、多个不同角色。
```

## 英文版（Midjourney / DALL·E / GPT-Image 等）

```
using my uploaded character as reference, draw the same character's walk cycle,
chibi pixel art, 16-bit game style, thick dark outline, crisp clean pixel edges, no anti-aliasing.

one horizontal row of 6 poses, left to right forming a complete walk cycle:
left foot up, land, right foot up, land...
all 6 poses exactly the same size, feet on the same horizontal line, evenly spaced,
front or three-quarter view, natural cute motion.

background: solid magenta #ff00ff, no ground, no shadow.
NO text, NO watermark, NO logo, NO glow, NO blur, NO different characters.
--ar 3:1 --style raw
```
