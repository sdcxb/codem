# 怎么用（30 秒看完）

## 第一步：打开一个提示词文件，全选复制

文件都在这个文件夹里，每个文件**只有一个提示词**，直接复制里面灰色框里的文字。

- 想画图书馆 → 打开 `01-图书馆场景.md`
- 想画某个岗位的角色 → 打开 `02-队长.md` ~ `11-休息员.md`
- 想给角色加动作 → 打开 `12-走路动作.md` ~ `16-出错动作.md`

## 第二步：粘贴到绘图模型，生成图片

即梦、豆包、Seedream、Midjourney、DALL·E 都可以。

每个文件里都给了**中文版**和**英文版**两段：
- 中文模型（即梦/豆包等）用中文版
- 英文模型（Midjourney / DALL·E / GPT-Image）用英文版

## 第三步：把场景图直接用起来（不用等我）

**场景图（图书馆地图）**可以自己在插件里换：

1. 打开 Codem → 左下角/右侧的 **图书馆运营监控** 胶囊 → 「设置」页签 → **场景图片** 卡片
2. 点「点击选择图片」选你生成的那张图（或者直接把图片**拖到场景上**松手）
3. 立刻生效，下次打开 Codem 还是这张图；点「删除我的上传」就能回到内置场景

> 换图只换「画面」，角色站位和岗位位置不变。如果图里的房间和参考框没对齐，
> 打开「对位编辑器」（设置 →「场景图片」→ 打开对位编辑器，或场景右下角 ✥ 按钮），
> 直接**把房间框拖到图里的房间上、把圆点拖到走道上**，角色就会按新位置走动；对位按每张图分别保存。

**角色 / 动作图**（带纯品红背景的）请丢进下面这个文件夹，切图、去背景、对齐、接进插件由我来做：

```
C:\mimo-gui\.art-inbox\
```

文件名随便写，能看出是什么就行，例如：

- `场景.png`
- `队长.png`
- `程序员.png`
- `走路-队长.png`

放好后跟我说一声「图放好了」，剩下的我全做。

---

## 小提醒

- 生成不理想就多点几次重来，挑最好的一张；
- 场景图尽量 **16:9 横版**（如 2752×1536），比例差太多会被拉伸（插件会提醒）；
- 角色图一定要**纯品红色背景**（提示词里已经写了），这是后面自动去背景用的；
- 一次生成一张就行，别贪多。
