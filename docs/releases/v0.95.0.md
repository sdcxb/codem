# Codem v0.95.0

**发布日期**：2026-08-06
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.95.0` 构建。

## 本版要点

- Vision Proxy 视觉代理支持 MiMo v2.5，视觉侧模型选择更多。
- CLI 与 API 双模式下的视觉代理全链路打通，CLI 模式也能取到 API Key。
- CSP 全面修复：补齐 media-src / font-src / frame-src，放行 blob: 与 asset.localhost。
- 打包后视频、音频、字体、iframe 与 blob 图片不再被安全策略拦截。
- 梦幻皮肤的视频背景在打包版中可正常显示。
- 梦幻皮肤花瓣装饰缩小，视觉上不再压住内容。
- 新增 13 个 E2E 全场景链路测试，覆盖 CLI / API 与各模型组合下的代理链路。
- 仓库清理：移除对标分析与培训类内部文档，README 宣传图片改为可正常访问。

## 变更（自上一版本以来）

### 新增

- Vision Proxy 新增 MiMo v2.5 视觉支持，并更新相关测试断言。
- 新增 13 个 E2E 全场景链路测试，覆盖 CLI / API 模式与各模型组合的视觉代理链路。

### 改进

- CSP 全面修复，新增 media-src / font-src / frame-src，并放行 blob: 与 asset.localhost，解决打包后视频、音频、字体、iframe 与 blob 图片被阻止的问题。
- resolveVisionConfig 改为从 engine 获取 CLI 模式下的 API Key，CLI 与 API 双模式链路一致。
- 梦幻皮肤花瓣装饰缩小：左上由 120px 调整为 60px，右下由 150px 调整为 75px。
- 清理 docs 目录下 58 个内部文档，仓库更干净。
- 移除对标分析文档 codex-use-cases 与培训文档 training，并加入 gitignore。

### 修复

- 梦幻皮肤视频背景插入到 document.body，避免被 React 渲染覆盖，同时修复打包后的 CSP media-src 限制。
- README 宣传图片移到 screenshots 根目录，避免 raw.githubusercontent.com 访问受限导致图片不显示。
- 修正图片扩展名：实际为 PNG 格式，由 .jpg 改为 .png 并更新 README 引用。
- 放行 README 引用的宣传图片，确保图片与 README 处于同一 tree 中可正常渲染。

> 改动规模：189 files changed, 699 insertions(+), 27733 deletions(-)
