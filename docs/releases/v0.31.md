# Codem v0.31

**发布日期**：2026-06-28
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.31` 构建。

## 本版要点

- 首个以 tag 形式发布的可用版本：Codem 桌面客户端以 Tauri + React + TypeScript 构建，可在 Windows x64 上运行。
- 支持 API 模式接入 DeepSeek 模型，在界面内即可完成配置与调用。
- 对话消息会持久化保存，切换模型前先把消息写入存储，历史对话不再丢失。
- 流式输出与工具调用显示得到修复，长回答可以边生成边看到。
- 调整登录流程与消息格式兼容性，为后续接入更多模型服务商打底。

## 变更（自上一版本以来）

### 新增

- 初始版本发布：Codem 编码助手客户端首次完整提交，技术栈为 Tauri + React + TypeScript。
- 新增 API 模式下的 DeepSeek 支持，可在 API 模式中直接调用 DeepSeek 模型。
- 新增使用指南文档、作者说明，并在 README 中加入界面截图。

### 改进

- 消息格式兼容性改进，不同模型返回的消息结构可以统一处理。
- 重构代理循环（agentic loop），任务执行流程更清晰。
- 流式输出优化，模型回复的流式渲染性能提升。
- 更新变更日志，把当日完成的修复记录进去。

### 修复

- 修复消息持久化问题：切换模型前先保存消息，避免对话内容丢失。
- 修复文本编码问题，消除乱码。
- 修复登录流程中的问题，登录可以正常完成。
- 修复工具调用显示缺失的问题（该问题此前在两种模式下都被记录为待解决）。
- 修复模型同步问题，模型列表与实际可用模型保持一致。
- 移除诊断用的调试代码。
