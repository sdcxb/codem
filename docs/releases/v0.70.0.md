# Codem v0.70.0

**发布日期**：2026-07-06
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.70.0` 构建。

## 本版要点

- 全部数据迁移到 SQLite 存储，不再依赖 localStorage，会话与设置更可靠。
- 全面修复中文编码问题，覆盖 glob、bash、PowerShell、Python 工具链路。
- 重构子智能体系统，采用 fork-join 协作模式并配套强身份提示词。
- 系统提示词优化：默认中文回复、完成后给出回执、脚本执行规则更明确。
- 工具能力增强：glob 支持中文匹配、文件内容增加包装、新增重复调用循环检测。
- 暂停策略对齐 Codex：暂停主任务不再连带影响正在运行的子智能体。
