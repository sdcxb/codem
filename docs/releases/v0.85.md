# Codem v0.85

**发布日期**：2026-07-19
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.85` 构建。

## 本版要点

- 技能触发机制做了三层改造：系统提示词强制先扫描可用技能、元技能可预加载完整指令、用户可在输入区显式选择技能并标记为 `[USER SELECTED]`。
- 附件系统全面重构：Inline 预览、按需读取、沙箱同步、`read_attachment` 工具与数据库持久化一次到位。
- 修复了全局对话无法写入数据库的关键缺陷（session / message / attachment 全部丢失的问题）。
- 新增技能市场，可以直接从 GitHub 仓库源搜索并一键安装技能。
- Web 搜索工具集成，支持 CLI 与 API 双模式，并跟随用户设置实时重配置。
- 新增 prompt-optimization、interactive 等高级技能，以及知识笔记本模块。
- 修复侧边栏滚动问题，项目树与全局对话增多后设置按钮不再被挤出视口。
- 新增 6 个测试文件、253 个测试用例，测试总数达到 1441 个并全部通过。

## 变更（自上一版本以来）

### 新增

- 技能触发机制三层改造：Skills First Principle 由系统提示词注入强制指令，处理任务前必须先扫描可用技能；元技能标记 `forcePreload` 后完整指令直接注入系统提示词；输入区新增技能选择按钮，用户选中的技能会标记 `[USER SELECTED]`。
- 附件系统新增 Inline 预览与按需读取，共享 3000 token 预算并按 head/tail 截断。
- 附件系统新增沙箱文件同步，附件会同步到项目的 `.attachments/` 目录。
- 新增 `read_attachment` 工具，支持按 ID 或名称查找、分页输出，并可跨会话复用。
- 新增提示词注入防护的数据隔离标记。
- 新增 Web 搜索集成：`web_search` 工具支持 CLI / API 双模式，自动跟随用户设置。
- 新增技能市场客户端，支持从 GitHub 仓库源搜索和安装技能。
- 新增技能安装器，支持从市场一键安装。
- 新增 prompt-optimization 技能，可查看和修改系统提示词，并提供交互式变更审查。
- 新增 interactive 技能，通过表单收集用户输入。
- 新增 `PromptChangeReviewDialog` 与 `InteractiveFormDialog` 组件。
- 新增 NotebookManager 组件与 `src/core/knowledge/` 知识模块。
- 数据库 `attachments` 表新增 `message_id`、`preview`、`sandbox_path` 列，实现附件持久化。
- 设置保存会触发 `codem-settings-changed` 事件，引擎据此实时重配置。
- 新增 6 个测试文件、253 个测试用例（attachment-system、skill-trigger-mechanism、global-chat-persistence、phase-b-f-regression、refactor-prompt-to-data、encoding-tools），测试总数 1441 个全部通过。

### 改进

- 提示词约束重构为运行时数据层约束：放弃在系统提示词中写死编码与路径规则，改为在运行时由数据层注入。
- 子智能体的 Windows Chinese Encoding Rules 迁移为工具执行层约束。
- SkillManager 界面大幅增强。

### 修复

- 修复全局对话持久化：此前全局对话的 session、message、attachment 无法存入数据库，根因是 `sessions` 表的外键约束引用 `projects(id)` 而全局 project 记录不存在；现在由 `initDatabase` 自动种子全局 project 记录，并在 `listProjects` 中过滤该记录。
- 修复侧边栏滚动：项目树展开或全局对话增多后设置按钮被挤出视口，改为 header/nav 固定不缩放，统一在 `.sidebar-scroll` 容器内滚动。
- 修复 `parseSkillMarkdown` 的 CRLF 兼容性问题。
- 修复 `global-chat-persistence.test.ts` 中 Message 类型的 import 路径。

> 改动规模：107 files changed, 58766 insertions(+), 1860 deletions(-)
