# Codem v0.89.0

**发布日期**：2026-07-26
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.89.0` 构建。

## 本版要点

- 新增跨会话 Agent 协作：一个会话可以把任务委派给另一个会话，并等待、查询结果，会话之间通过事件总线实时通信。
- 新增 8 个高级功能面板，集中在设置 →「高级」：智能体管理、心跳监控、重试配置、提示词调试、分层设置、会话恢复、工具管理、委派任务。
- 核心模块配置持久化：自定义智能体、心跳参数、重试参数、会话恢复数据改为落 SQLite，重启后不再丢失。
- 新增上下文压缩参数配置界面：可调压缩触发阈值、压缩所用模型、最大保留消息数与摘要长度限制，改动下次压缩即生效。
- 新增 30 条发布阻断级冒烟用例：覆盖初始化、消息链路、工具与智能体注册、会话与权限、本版新增模块、系统提示词与上下文，运行 30 秒内完成。
- 新增 185 条回归用例（含冒烟用例），分 9 个模块核对持久化、消息链路、工具权限、提示词构建与会话恢复。
- 修复三类导致编译失败的类型问题，以及跨会话模块缺少导出、导入路径错误等运行期问题。

## 变更（自上一版本以来）

### 新增

- 跨会话事件总线：支持委派、结果、状态、取消四类消息，发布订阅模式，会话之间实时传递。
- 委派编排器：负责委派任务的调度，含环形委派死锁检测、并发上限与超时管理。
- 会话执行器：可由程序触发指定会话执行一轮，支持中途取消与待处理委派的收尾。
- 委派任务存储：SQLite 持久化委派任务，支持创建、按会话查询、按标识读取、状态更新与清理。
- 委派工具集：供模型调用的委派、等待委派、查询会话结果、列出会话四个工具。
- 高级功能面板共 8 个：智能体管理（查看/编辑/注册自定义智能体、权限规则可视化）、心跳监控（实时状态与全局参数）、重试配置（最大重试、基础延迟、倍率、上限、总超时）、提示词调试（完整系统提示词、智能体提示词、变量注入预览）、分层设置（展示各层设置来源与最终生效值）、会话恢复（浏览/恢复/删除历史会话）、工具管理（已注册工具、参数结构、权限规则）、委派任务（活跃与已完成委派追踪）。
- 上下文压缩配置界面：设置面板新增「上下文压缩」区域，可视化调整压缩参数。
- 冒烟测试套件：30 条发布阻断级用例，任一失败即阻断发布。
- 回归用例 V2：185 条用例覆盖智能体注册表、心跳、重试、设置键冲突、Git/Worktree/环境对核心链路影响、消息链路与存储完整性、工具调用与权限、系统提示词构建、会话恢复等模块。

### 改进

- 智能体注册表持久化：自定义智能体的加载、保存、更新、注销与内置判定，写入设置存储。
- 心跳管理器持久化：全局心跳配置可读取与写回，重启后保持。
- 重试执行器持久化：指数退避相关配置可读取与写回，重启后保持。
- 会话恢复服务持久化：恢复数据写入数据库表，支持加载与保存。
- 成本追踪与用量统计增强；引擎初始化与提示词构建链路增强。
- 上下文监控组件同步展示压缩参数。

### 修复

- 修复事件总线类缺少导出导致界面黑屏的问题。
- 修复会话执行器与委派工具的导入路径错误。
- 修复 TypeScript 编译错误：上下文配置私有成员访问、权限请求类型、子智能体派发接口定义。
- 修复冒烟测试中对智能体定义的类型断言缺失。
