# Codem v1.16.310

**发布日期**：2026-10-10
**类型**：稳定版（Windows x64）
**下载**：`Codem_1.16.310_x64-setup.exe`（NSIS 安装包）· `Codem_1.16.310_x64_en-US.msi`（MSI）

## 本版要点

1. **装好即用的免费模型** —— 内置开源项目 **Our Free Model**（MIT）的本地服务：一个只监听本机回环地址的
   小程序，**不需要登录、注册或填 API Key**，模型清单跟随上游刷新。安装后**默认开启**，对话的模型列表会
   **优先**显示它当前可用的免费模型（取不到时自动回退到你自己配的模型，列表不会空）。
2. **它需要的运行环境由 Codem 自带，你不用装任何东西** —— 这个插件是一个 Node 程序，本版把所需的
   Node 运行时**随安装包内置**（取自官方发行包并校验 SHA256）：你机器上已有够新的 Node 就用你的，
   没有就用内置的那份。**「请先安装 Node.js」这种提示不会再出现。**（安装包因此从约 46MB 变为约 68MB。）
3. **它完全独立，随时可以关掉** —— 「插件管理 → 插件市场」里有一张卡片：开启 / 暂停 / 删除，
   上面如实写着它现在的状态、用的是哪一份 Node、跑在哪个端口。暂停只停进程（数据保留），删除连数据一起清掉；
   两种操作都会把它登记的那条供应商一并撤销，**你原有的模型、密钥、对话一点都不受影响**。
4. **修好了"检查更新时看不到进度"** —— 以前下载新版本时只有一句静态的"下载中…"（而且底层报的下载字节数
   根本没人接）。现在会显示一根真的进度条：知道大小时显示 `12.3 MB / 46.1 MB（27%）`，
   不知道大小时显示"已下载 x MB"并来回走动（不编造百分比）；下载被掐断自动重试时进度归零重算。

## 变更

### 新增
- 内置 Our Free Model 的本地服务（OpenAI 兼容：`/v1/models`、`/v1/chat/completions`，含流式）。
- 模型列表优先级：开启时它的清单排在最前；未启用 / 未就绪 / 缓存过期时**原样回退**。
- 「插件管理 → 插件市场」新增控制卡片：状态（端口、模型数、进程号、Node 来源）、开启 / 暂停 / 删除 / 刷新，
  以及未就绪时**它自己的运行日志**（不再是只说一句"失败了"）。
- 随安装包内置 Node 运行时；解析顺序为**系统（够新）→ 内置 → 便携 →（都没有才）下载**。
- 缺 Node 时的兜底：应用内提示框可直接「现在安装」（约 30MB，装完自动把插件启动起来），
  选「以后再说」不再提醒。

### 修复
- **检查更新的下载进度**：以前没有进度条、也没接下载事件；现在有真进度条（含总量未知时的不确定态）。
- 插件上次异常退出（崩溃 / 被强制结束）留下的运行锁会让它拒绝再启动：现在会自动确认"锁的主人确实不在跑了"
  再清理，不用你手工处理。
- 暂停插件后，模型列表里最长一分钟还会挂着调不通的免费模型：现在暂停 / 删除会**立刻**撤下来。

### 说明
- 该插件是**第三方开源项目**（MIT），随安装包提供；构建时按固定版本获取并逐文件、逐字节校验。
  它发出的请求**直达上游公开网关**（不是 Codem 的服务器）。上游的免费池会在其模型卡中声明
  "提示词可能被记录用于改进服务" —— **请不要用它发送敏感内容**。
- 插件的账号渠道（十三个第三方账号通道）本版没有启用，免费模型不需要任何账号。

## 对标结果

**本版未重跑对标评测**，沿用上一稳定版的结论：在 **12 个真实仓库修复任务**上，本版通过 **10 个**，
参考实现（DSH，同一套任务、同一模型）通过 **9 个**；完成同样任务所需的工具调用约为参考实现的一半，
输出 token 用量明显更少；单次响应时延仍慢于参考实现（取决于模型服务端，客户端侧不是瓶颈）。

本版改动集中在"内置插件 / 运行环境自带 / 更新进度显示"，没有触碰 agent 循环与工具链路，
因此沿用上面的数字。

## 升级说明

- 覆盖安装即可；已有的会话、记忆、待批准条目、供应商与设置原样保留。
- 安装包变大（约 46MB → 68MB）是因为**内置了 Node 运行时**（约 88MB 解压后）。
- 升级到本版之后，检查更新时就能看到下载进度条了。
- 不想要这个插件：卡片上点「暂停」（保留数据）或「删除」（清掉数据），之后不会再自动启动。

## 已知问题

- 输入框里的模型下拉在本版是**展示用**（清单会优先列出免费模型，切换模型要到"档案 / 设置"里选）；
  "点一下就把当前对话切到某个免费模型"会在后续版本里补。
- 插件把免费模型分了"可用 / 地区受限"两组，个别模型可能被上游拒绝（例如
  `Model does not support this protocol.`）——那是上游对该模型的限制，插件仍会列出它。
- 免费池由上游免费提供，可用性与速度随上游波动；它不是 Codem 的服务，也不能保证长期可用。
- 如果 Codem 是被**任务管理器强制结束 / 断电**而不是正常退出，会留下一个插件进程占着端口；
  插件会自己换端口继续工作（功能不受影响），正常退出时会一起收掉。

## 校验

- 附更新器签名 `.sig`；`latest.json` 平台键为 `windows-x86_64-nsis` 与 `windows-x86_64`（同一份签名）。
- 安装包 sha256 与更新器清单一致（可用仓库内 `tools/release/verify-update-manifest.mjs --remote` 复核）。
