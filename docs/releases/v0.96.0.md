# Codem v0.96.0

**发布日期**：2026-08-08
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.96.0` 构建。

## 本版要点

- 主对话窗口 UI 大改版，对话阅读与操作路径整体重做。
- 文件改动改为内联 Diff 批量审批，替代原来的弹窗逐条确认。
- 三套皮肤的暗色模式深度修复，暗色下不再有看不清的界面。
- 梦幻皮肤支持自适应主题，跟随调色板明暗自动切换。
- 新增富内容渲染系统，由 9 个组件覆盖对话中的富文本内容。
- 代码块接入 Shiki 语法高亮，代码阅读更清晰。
- 本版新增 39 个组件，界面能力大幅扩充。
- 引入 framer-motion / shiki / xlsx 三个新依赖，支撑动画、高亮与表格解析。
