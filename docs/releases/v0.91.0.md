# Codem v0.91.0

**发布日期**：2026-08-01
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.91.0` 构建。

## 本版要点

- 终端从一次性执行升级为 PTY 交互式：可开多个终端页签、真实交互、按停止按钮或 Ctrl+Shift+C 中断当前进程，窗口缩放自动同步行列。
- 文件变更全量追踪：每轮迭代自动记录改动前后的文件树与二进制 diff（含 SHA-256 校验），形成可回看的 Artifact 快照，并支持回滚该轮改动。
- 文件树显示 Git 状态徽章（修改/新增/删除/未跟踪/重命名），Agent 改完文件后文件树自动刷新。
- 新增变更历史面板与 Diff 面板：按轮次分组展示改动文件与摘要，点击文件即可对比前后内容。
- 支持自动 Git 提交：一轮改动结束后可自动生成提交信息并提交，Git 信息面板随之刷新，开关在 Git 偏好设置中。
- Agent Profile 持久化：可为子智能体保存身份、领域、范围、技能与经验摘要，生成子智能体时自动注入到系统提示词。
- 新增 Needs You 精确提问与异步 Agent 间通信：Agent 在工作途中向你提出带候选答案的精确问题，Agent 之间也可异步留言并在迭代边界收到。
- 新增浏览器预览面板与 Overview 可观测性三视图（执行中工具 / 容量 / 变更时间线）。

## 变更（自上一版本以来）

### 新增

- PTY 交互式终端：新增终端进程的创建、写入、尺寸调整、关闭四组后端命令，终端面板支持最多 5 个会话页签与 30 分钟空闲自动清理。
- 终端交互细节：Ctrl+C 改为仅复制、无选区时不发信号以免误中断，Ctrl+Shift+C 发送中断信号，工具栏新增停止按钮，窗口尺寸变化经观察器同步到终端的列数与行数。
- 文件变更追踪：新增记录每轮文件变更的数据库表，保存改动前后文件树、二进制 diff、diff 摘要校验值、本轮简述与变更文件清单。
- 变更追踪存储层：提供创建、按会话列出、按标识读取、状态更新、按会话删除与变更清单解析。
- Artifact 快照：变更记录的标识即 Artifact 标识，配合 diff 校验值保证完整性，迭代循环在改动前后自动开始与收尾并广播变更事件。
- 变更回滚：可通过反向应用 diff 撤销指定轮次的改动；非 Git 工作区自动跳过而不报错。
- 文件树 Git 状态：解析 `git status --porcelain` 并缓存，文件名右侧显示 修改/新增/删除/未跟踪/重命名 徽章。
- 变更历史面板：按轮次分组，展开显示文件列表、本轮摘要与回滚按钮；侧边栏新增「文件」与「变更」两个页签。
- 自动 Git 提交：提交信息支持由模型生成或启发式回退，一轮变更收尾后自动触发，Git 信息面板监听提交事件自动刷新，开关持久化。
- Transcript 缓存：以内容哈希为键缓存模型请求与响应，10 分钟过期、最多 100 条，上下文压缩完成时自动清空。
- Agent Profile 持久化：新增智能体档案表，保存身份、领域、范围、技能与经验摘要；子智能体任务新增档案引用字段，派发时若指定档案则注入系统提示词。
- Needs You 精确提问：新增向人提问的反向队列（在迭代边界消费，避免阻塞工具回调）、提问面板（当前工作 + 已确认事实 + 精确问题 + 候选选项 + 自定义回答）与持久化表，支持会话恢复与「跳过并继续」。
- 异步 Agent 间通信：新增消息队列（发送、消费、取回复、订阅）与独立于消息记录的消息表，迭代边界消费并作为用户消息注入供下一轮读取。
- 浏览器预览面板：新增创建与关闭独立 WebView 窗口的后端命令，可按地址预览页面。
- Overview 可观测性：代码工作台改为执行中工具、修改文件与增删行统计、变更时间线三个视图。
- 集成配套界面：Git 偏好设置新增自动提交开关；设置「高级」新增档案管理子标签（查看/创建/编辑/删除）与缓存统计子标签（占用进度、清空、刷新）。

### 改进

- 界面设计完整版改造：新增自定义缓动曲线并全局替换内置缓动；三套皮肤共 51 处 `transition: all` 全部改为具体属性过渡。
- 交互反馈：所有可点击元素按下时缩放至 0.97 并有短促过渡，菜单与弹出层从触发源位置展开（模态框保持居中）。
- 可访问性：系统开启减少动效时全局降级为透明度过渡，减少透明效果时磨砂玻璃降为纯色，梦幻皮肤另有专属降级。
- 材质分层：导航与工具栏使用更强的模糊与饱和度，弹出面板使用较弱一档；滚动边缘以渐变遮罩替代硬边框。
- 入场动画改为可中断可重定向的过渡写法，并保留旧关键帧兼容。
- 终端跨平台：非 Windows 平台按 `$SHELL` 选择 shell，依次回退 zsh → bash → sh。
- 档案管理、变更面板中的 Diff 对比、提问面板等本版新增界面均已完成接线与验证。

### 修复

- 大改动预检查：diff 超过 20 万行或超过 100 个文件时跳过全量 diff 生成，避免占用内存过高，单文件对比仍可按需查看。
- 变更记录与 Agent 消息存于独立数据表，不受上下文压缩影响，压缩后仍可回看与回滚。
- 新增 4 个测试文件共 101 条用例（覆盖终端、变更追踪、Git 状态、自动提交、档案、提问、消息队列与交叉影响）；全量回归 2770 条全部通过，编译与静态检查零错误。
