# Codem v1.16.312

**发布日期**：2026-10-12
**类型**：稳定版（Windows x64）
**下载**：`Codem_1.16.312_x64-setup.exe`（NSIS 安装包）· `Codem_1.16.312_x64_en-US.msi`（MSI）

## 本版要点

1. **修好了"升级时提示某个文件写不进去"**：点升级、下载完开始安装时，安装程序会在最后一步弹出
   「无法打开要写入的文件：…\Codem\resources\node\node.exe」，只给你 [Abort] / [Retry] / [Ignore]
   三个选择（Retry 会一直循环）。
   - **为什么会这样**：为了让"没装 Node 的电脑也能用内置的免费模型"，上一版把 Node 运行时**放进了安装目录**；
     而你机器上没有够新的系统 Node 时，免费模型插件会**直接运行安装目录里那一份** ⇒ 安装程序要覆盖它时，
     它正被进程占用。
   - **现在怎么修的**：插件改为运行**数据目录里的副本**（首次使用时自动从安装目录复制一份）——
     安装目录从此只剩只读资源，升级随时可覆盖；被强制结束留下的残留进程也不会再挡住升级。
     另外，**应用内点升级时会先把插件停掉**再安装（停掉不等于禁用，装完重启会自动恢复运行）。
   - ⚠️ **如果你这次正好卡在这一步**：先**完全退出 Codem** 再装，或者直接点 **[Ignore]**
     （两个版本内置的是同一个 Node v24.19.0，跳过这个文件没有任何副作用）。**别点 [Retry]**。
   - 如实说明：上面那层"插件改用数据目录副本"的改动，在**没有系统 Node 的电脑**上我们还没有实测读数
     （开发机上装着够新的 Node，走不到那条分支）。所以万一你升级时**仍然**遇到同一个提示，
     用上面的办法即可完成升级；本版之后从本版再往上升级不会再被它挡住。
2. **切换对话时，打开的浮层会自动收起**：以前在对话里点开模型列表后直接切到另一个对话，
   列表不会关，会**贴在新切换过来的对话上面**（挡住正文）。这类浮层（模型列表、推理强度、
   各类面板、搜索、快速短语等）现在都会在切换会话时一并收起。
   - 注意：**常驻偏好不受影响** —— 右侧栏、快捷入口、是否显示思考过程是你在设置里显式选择的，
     切换对话时不会被动关掉。

## 变更

### 修复
- 应用内升级报「无法打开要写入的文件：…\resources\node\node.exe」（内置 Node 不再从安装目录运行；
  升级前先停插件释放句柄）。
- 切换对话时模型列表等浮层不自动收起（导致旧会话的列表盖住新会话）。

## 对标结果

**本版未重跑对标评测**，沿用上一稳定版的结论：在 **12 个真实仓库修复任务**上，本版通过 **10 个**，
参考实现（DSH，同一套任务、同一模型）通过 **9 个**；完成同样任务所需的工具调用约为参考实现的一半，
输出 token 用量明显更少；单次响应时延仍慢于参考实现（取决于模型服务端，客户端侧不是瓶颈）。

本版改动只涉及"内置 Node 的存放位置 / 升级前的收尾"与"界面浮层的收起时机"，没有触碰 agent 循环与工具链路。

## 升级说明

- 覆盖安装即可；已有的会话、记忆、待批准条目、供应商与设置原样保留。
- 升级过程中若弹出「无法打开要写入的文件」，**先退出 Codem 再装**或点 **[Ignore]**（见上文）。
- 升级完成后，免费模型插件会自动恢复运行，无需重新配置。

## 已知问题

- 「插件改用数据目录副本」这一改动在**没有系统 Node 的电脑上尚未实测**（见上）。
- 免费池是**第三方公开网关**（不是 Codem 的服务器），其模型卡里声明"提示词可能被记录用于改进服务"
  —— **请不要用它发送敏感内容**；个别模型可能临时不可用，换一个 `-free` 模型即可。
- 如果 Codem 是被**任务管理器强制结束 / 断电**而不是正常退出，会留下一个插件进程；
  正常退出时会一起收掉，且它已不再占用安装目录（不影响升级）。
- 模型清单里的免费模型来自上游实时列表，**上游改了就跟着变**，这是预期行为。

## 校验

- 附更新器签名 `.sig`；`latest.json` 平台键为 `windows-x86_64-nsis` 与 `windows-x86_64`（同一份签名）。
- 安装包 sha256 与更新器清单一致（可用仓库内 `tools/release/verify-update-manifest.mjs --remote` 复核）。
