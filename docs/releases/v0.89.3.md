# Codem v0.89.3

**发布日期**：2026-07-27
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.89.3` 构建。

## 本版要点

- 宠物窗口改为独立轻量入口：不再加载主应用整包，脚本体积从 3.4MB 降到 5.7KB，宠物进程内存明显下降。
- 宠物窗口尺寸变化不再漂移：以精灵图水平中心与底部为锚点，位置与尺寸一次设定，气泡出现或消失时宠物在屏幕上保持不动。
- 气泡尺寸按文本实测：用 canvas 逐字符测量文本宽高，中英文混排都能精确容纳，气泡消失后窗口立即缩回紧凑尺寸。
- 修复应用重启后模型与模式恢复不正确的问题：启动时会在数据库就绪后再读取持久化设置，退出前会把待写入数据立即刷盘。
- 宠物状态补全 waiting / review / waving 三种，动画表现与智能体实际阶段对应更准确。
- 修正模型列表过滤与模型配置面板布局问题。

## 变更（自上一版本以来）

### 新增

- 宠物窗口多页打包：新增宠物专用 HTML 入口、专用 React 轻量入口与专用最小样式表，构建配置纳入该入口，切断对主应用整包的依赖。
- 宠物窗口锚点调整命令：Rust 端读取当前窗口物理位置与尺寸，以精灵图水平中心加底部为锚点，单次调用同时设置新位置与新尺寸，全程无异步间隙。
- 气泡文本测量：前端改用 canvas 实测文本宽高（逐字符换行，兼容中英文混排），只把目标宽高交给后端，不再自行推算窗口位置。
- 宠物动画工具函数；宠物类型定义扩展。

### 改进

- 宠物窗口内存占用下降：脚本体积 3.4MB → 5.7KB（约 -99.8%），WebView2 宠物进程内存大幅降低。
- 初始窗口尺寸按「精灵图宽 ×（精灵图高 + 预留最小气泡高度）」计算，事件气泡出现时动态扩展，消失后缩回紧凑尺寸。
- 宠物状态标签补全 waiting / review / waving，覆盖更多智能体阶段。
- 模型选择面板的列表过滤逻辑修正，模型配置面板布局修复。
- 本地嵌入的 WASM 路径适配。

### 修复

- 修复应用重启后对话框顶部模型默认显示 `mimo-v2.5-pro`、而非上次使用的 API 模式与模型的问题；根因是数据库异步初始化未完成时读取到空设置、以及关闭时防抖写入丢失。
- 数据库初始化完成后同步重新配置引擎，确保读取到已持久化的模式与模型。
- 应用关闭流程中立即刷盘，避免防抖窗口内退出导致最后一次设置写入丢失。
- 清理发布说明临时文件并更新依赖锁定文件。
