# Codem v0.80.1

**发布日期**：2026-07-14
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.80.1` 构建。

## 本版要点

- 新增全局对话：侧栏出现独立的全局对话区域，不挂靠任何项目的对话也能创建、分组与置顶。
- 新增任务完成通知：应用在后台或最小化时，任务完成会弹出窗口并发送系统原生通知。
- 修复切换历史对话时子智能体状态闪烁为「运行中」或消失的问题。
- 优化新建对话速度：数据库保存改为防抖，新建对话从数秒变为即时。
- 修复设置面板读不到引导流程保存的用户信息、以及状态库 API 调用报错的问题。

## 变更（自上一版本以来）

### 新增

- 新增全局对话区域，展示 `projectId = ""` 的会话，支持时间分组、置顶等完整会话功能；「新对话」按钮始终创建全局会话，项目内新建对话交由项目旁的 `+` 按钮负责。
- 新增任务完成通知（对标 Codex）：最小化或后台运行时任务完成会通过 Tauri 弹出并聚焦窗口，同时发送系统原生通知，通知标题为「任务完成 — 对话标题」。
- 新增通知相关依赖与权限：`@tauri-apps/plugin-notification`、`tauri-plugin-notification`，并在 Tauri capabilities 中开放对应权限。

### 改进

- 新建对话速度从 4~5 秒优化到即时：数据库全量保存从每次调用即写改为 500ms 防抖，并移除新建会话中嵌套的 `setTimeout`；同时新增即时落库入口，供需要立刻保存的场景使用。
- 设置面板打开时会从 `codem-user` 读取引导流程保存的称呼与用户信息。
- 引导流程保存后立即回读校验，便于确认保存结果。

### 修复

- 修复切换历史对话后子智能体状态短暂闪烁为「运行中」或消失的问题：初始状态改为不渲染任何内容，并在内存任务信息不可用时回退使用工具调用状态。
- 修复状态库调用 `set(...)` 报错的问题，改为 `setState(...)`。
- 修复发送消息与运行循环时读取到过期会话的问题，改为每次都取最新会话，避免闭包过期。

> 改动规模：22 files changed, 1080 insertions(+), 99 deletions(-)
