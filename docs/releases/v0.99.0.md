# Codem v0.99.0

**发布日期**：2026-08-14
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.99.0` 构建。

## 本版要点

- 会话改为事件溯源日志：每次对话以 SessionEvent 记录，可回放、可分叉、可投影出消息视图。
- 工具调用改为五层管线，前置校验、单调性守卫、执行、后置处理与收尾各有独立环节。
- Plan Mode 增强，新增 exit_plan_mode 工具与 PlanApprovalCard 审批界面，计划先确认再执行。
- Capability Seam 拆出 ServiceDefinition / Provider / Consumer 三种角色，文件与终端能力可替换实现。
- Code Mode 支持用 run_code 执行 TypeScript，并配套 ToolSDK 供脚本调用工具。
- 会话历史接入 FTS5 全文搜索，长对话里找内容不再靠翻页。
- 目标可自动续行，create_goal / get_goal / update_goal 配合 Goals 表让长任务跨轮继续推进。
- 其余新增能力还包括 Workflow 编排、Telemetry 采集、MCP 市场、Ollama 本地模型、技能沙箱与远程同步。

## 变更（自上一版本以来）

### 新增

- 事件溯源会话日志：SessionEvent、deriveMessages、Replay、Fork、Projection。
- 五层工具管线：pre-execute、monotonic-guards、execute、post-execute、finalize。
- Plan Mode 增强：新增 exit_plan_mode 工具，提示词对齐 6 段规范，并新增 PlanApprovalCard 审批界面。
- Capability Seam：ServiceDefinition / Provider / Consumer 三角色，配套 LocalFs、LocalShell Provider 与 SeamRegistry。
- Code Mode：run_code TypeScript 执行器与 ToolSDK。
- Session Query：基于 FTS5 的全文搜索。
- Goal 自动续行：create_goal / get_goal / update_goal 与 Goals 表。
- Workflow 编排：用 JavaScript 脚本派生（fan-out）子任务。
- Snapshot 测试：ReplayAdapter 支持录制与回放。
- Telemetry：OpenTelemetry 采集、telemetry_events 表与 PerformanceDashboard 性能面板。
- Bash 后台模式：JobManager 与 job_list / job_output / job_kill。
- 终端工具组：terminal_open / terminal_send / terminal_signal / terminal_close。
- MCP 市场：目录（catalog）、一键安装、分类搜索。
- 语音能力：useSpeechRecognition 与 useSpeechSynthesis，使用浏览器原生接口。
- Ollama 本地模型 Provider：REST API 接入、模型动态发现、离线推理。
- CI/CD 管理：GitHub Actions workflow 生成、运行监控与重试 / 取消。
- 技能安全沙箱：内容预检、哈希签名、权限声明与安装审计。
- 远程同步引擎：seq 增量同步，支持 Supabase / REST 后端。
- 多智能体协同架构、8 Tab 任务管理中心与 Inbox 通知聚合。
- 测试分层补齐：snapshot 与 e2e 配置，并补充防御性文档、ADR 与 Postmortem 体系。

### 改进

- 提示词改为 i18n 结构：prompt.ts 迁移为 i18n-templates.ts，支持双语模板。
- 代码质量工具接入：knip 检测死代码、jscpd 检测重复代码。
- 测试体系重建：删除 57 个虚假测试并修复其掩盖的真实缺陷；4 个源码字符串比对测试文件改写为真实行为测试，61 个用例开始验证实际行为。
- Node.js 由 20 升级到 22，LLMEngine 初始化移到 beforeAll，CI 环境更稳定。
- CI 输出处理改进：grep 之前先剥离 ANSI 颜色码；忽略 EnvironmentTeardownError。
- Agentic Loop 优化、技能市场扩充与发布功能完善。
- 本版累计修改 25 个文件（+1721 / -313 行），另有 50 多个新文件；全量 99 个文件 / 3234 个用例全部通过。

### 修复

- provider.ts 的 toAPIMessage 补全 ContentBlock 中 tool_use / tool_result 块的处理，修复事件投影路径下工具调用信息丢失。
- agentic-loop.ts 事件投影消息映射补全 tool_calls 属性，修复下游优先级排序、孤儿过滤与 micro-compact 全链路问题。
- tools.ts 的 readViaSeam 与 local-fs-provider.ts 的 readFile 补齐相对路径的 cwd 解析。
- session-storage 的 executionMode / worktreePath 持久化真正落地。
- 修正 session-storage 中 preserveExecutor 的类型应为 number 而非 boolean。
- 修复 streaming-executor 中 ctx.abort 的空值访问问题（由 CI 发现）。
- 修复 TypeScript 编译错误，解决硬编码路径、语法错误与异步生成器导致的 56 个测试失败。
- 移除仓库索引中内嵌的 git 仓库。
