# Codem v0.90.0

**发布日期**：2026-07-31
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.90.0` 构建。

## 本版要点

- 新增推理强度分档：可在模型选择器中直接切换低/中/高/超高四档，超高对应对高推理强度与 16384 输出上限。
- 输入区统一为一体化设计：上传文件、选择技能、生成图片、语音合成合并为一个「+」按钮，发送器右侧的上箭头按钮直接弹出快捷短语与提示词草稿。
- 滚动体验改善：滚动条上标注消息位置，底部提供未读提示与一键回到底部，并修好自动滚动与未读指示的冲突。
- 高级 Agent 能力落地：事实核查开关、主动澄清表单、可勾选并持久化的待办列表、引导消息折叠块、分阶段等待提示、重生成时换模型、消息赞踩与内联编辑。
- 多模态展示补齐：全屏图片画廊、视频播放器、生成模式与分辨率选择。
- 智能输入增强：上下文徽章、`@` 文件与笔记本补全、`/` 技能补全、知识来源选择器。
- 知识管理增强：笔记（含版本历史）、闪卡复习、知识图谱可视化、导入导出、学习路径生成、从知识库生成 PPT，并新增 DOCX/PDF 查看与统一笔记本工作台。
- 新手引导完善：仅首次启动显示，修复最后一步被窗口边界裁切的问题，设置页新增「帮助」可重新播放。
- 梦幻皮肤磨砂玻璃：侧边浮动弹窗、技能选择、命令菜单、模型选择器统一磨砂效果并适配暗色。

## 变更（自上一版本以来）

### 新增

- 滚动与阅读体验：滚动条消息标记、滚动到底部指示器与滚动状态钩子。
- 高级 Agent 功能：事实核查模式开关与核查结果面板、主动澄清表单、待办列表展示与勾选、引导消息折叠块、分阶段流式等待提示、代码工作台、重生成模型选择弹窗、消息赞踩（含持久化表）、消息内联编辑重发、模型能力守卫、多步骤任务选择、结构化输出解析与模型路由解析。
- 体验提升项：分类快捷短语模板、提示词草稿版本管理与 A/B 对比、Agent 快速访问卡片（收藏与搜索）、新手引导浮窗、RAG 来源引用芯片。
- 多模态展示：全屏图片画廊（左右切换、下载）、视频播放器（进度条、下载）、图片/视频生成模式切换、输出分辨率选择；消息附件类型扩展出视频。
- 智能输入：上下文徽章列表、`@` 提及补全、`/` 技能补全、知识来源选择器。
- 知识管理：笔记增删改查与版本历史、闪卡与复习调度、知识图谱的实体关系提取与可视化、知识导入导出（Markdown/JSON）、学习路径生成、PPT 生成、DOCX 查看、PDF 查看、来源内容查看、统一笔记本工作台、笔记本分组。
- 数据层扩展：新增 10 张数据库表（笔记、笔记版本、闪卡、图谱节点与边、快捷短语、提示词草稿、消息反馈等）。
- 新增公式与文档渲染相关依赖：katex、remark-math、rehype-katex、mammoth、pdfjs-dist。
- 推理强度分档：模型选择器底部新增四档切换，超高映射为高推理强度与 16384 输出上限。

### 改进

- 修复推理参数传递断点：推理强度参数此前被静默丢弃，现在会正确传给模型接口。
- 深度思考开关从「更多」菜单移到模型选择器中直接切换。
- 输入区一体化：上传文件、选择技能、生成图片、语音合成合并为统一「+」按钮，未配置多模态时禁用并给出提示；发送器右侧上箭头弹出快捷短语与提示词草稿；输入框内按钮垂直居中。
- 快速访问扩展到全部四个主 Agent（build/plan/explore/general）。
- 赞/踩按钮内联到复制与收起同一行，不再换行。
- 侧边弹窗统一为与主对话区同高并居右（多模态设置、智能体工作列表、文件快照、上下文监控），弹窗边界由样式变量动态测量。
- 会话类型新增事实核查模式、深度思考模式与执行器保留标记；消息类型新增元数据字段。
- 迭代循环新增澄清、核查完成、步骤完成、待办创建等事件。
- 界面文案补齐本版全部新增组件的翻译键，样式表新增约 1300 行组件样式。

### 修复

- 修复新手引导最后一步窗口偏下、内容显示不全的问题（按视口边界收敛并自适应位置）。
- 修复新手引导每次启动都弹出的问题，改为仅首次启动显示，设置页「帮助」可再次播放。
- 修复侧边弹窗关闭按钮与主窗口关闭按钮位置重叠。
- 修复自动滚动与未读指示器之间的交互冲突；修正编辑并重发时的会话级流式判断。
- 修复构建失败：编译时排除测试文件，避免测试代码进入发布构建。
- 梦幻皮肤侧边浮动弹窗磨砂缺失与暗色模式弹窗背景不适配的问题修复。
