# Codem v0.93.0

**发布日期**：2026-08-03
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.93.0` 构建。

## 本版要点

- Vision Proxy 视觉代理打通全链路：纯文本模型（DeepSeek）也能理解图片。
- 输入图片会被检测、智能路由到视觉模型生成文字描述，再用描述替换原图转发给主模型。
- 新增 STT 语音转写代理通路，语音可以先转成文字再交给当前模型。
- 新增图片生成通路，与视觉、语音转写并列为可路由的媒体能力。
- 多模态能力矩阵按输入（vision / stt）与输出（embedding / tts / imageGen）重构，能力声明更清晰。
- TaskSlot 新增 vision 槽位，任务执行链路上可以插入视觉处理环节。
- 新增内置方案「DeepSeek + 视觉代理」，开箱即可让纯文本模型处理图片。
- 本版补上 89 个媒体代理测试用例，全量 2859 个测试通过。

## 变更（自上一版本以来）

### 新增

- Vision Proxy 视觉代理全链路实现，纯文本模型（DeepSeek）获得图片理解能力。
- 语音 STT 代理通路、图片生成通路，以及音频 ContentBlock 支持。
- 多模态能力矩阵重构：区分 vision / stt 输入能力与 embedding / tts / imageGen 输出能力。
- TaskSlot 新增 vision 槽位。
- 内置方案新增「DeepSeek + 视觉代理」组合。
- 新增 Playwright、Figma、GitHub 三个 MCP 工具。
- 新增 Codex 用例复现路径分析（可复现与不可复现路径梳理、改造方案）与 101 个独立用例分析文档。
- v0.91.0 的 P0–P4 组件全部集成完成并验证，49 项集成测试通过。

### 改进

- 配置弹窗 z-index 层级修复，弹窗不再被其他面板遮挡。
- 完善 Vision Proxy 相关文档：配置入口修复说明、能力矩阵说明与对话窗口使用流程。
- 完全版 UI 改造：自定义缓动曲线、清除全局 transition:all、按压反馈、弹窗 origin、可访问性覆盖、材质分层与入出场动画现代化。
- 修正 tauri.conf.json 与 Cargo.toml 中的版本号，使构建产物版本一致。
- 历史聊天定位圆圈从右侧移到左侧，避免误触滚动条。
- 检查更新接口没有返回 JSON 时，自动打开 GitHub 下载页，不再只显示失败。

### 修复

- 梦幻皮肤透明度问题彻底修复：删除内联 background 让 CSS !important 生效，变量定义提升到 html 级别。
- 梦幻皮肤磨砂效果增强：透明度降到 0.78 / 0.82，让 backdrop-filter 真正可见。
- 文件浏览器漏加磨砂规则的原因查明：使用的是 .floating-explorer 类名而不是 .floating-overlay-panel，现已补上规则并用内联 style 兜底。

- 梦幻皮肤弹窗与定位圆圈改为内联 CSS 变量加磨砂效果，定位圆圈强制不透明，缩放至 28px 并回到右侧。
- 检查更新状态为 undefined 的显示问题修复。
- 新手引导改为仅首次启动显示。
- Rust 条件编译修复：shell 变量与 cmd 创建合并到同一 cfg 块。
