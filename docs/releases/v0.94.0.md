# Codem v0.94.0

**发布日期**：2026-08-03
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.94.0` 构建。

## 本版要点

- 配置方案弹窗改用 Portal 渲染，彻底解决被其他面板遮挡的问题。
- 新建方案后自动展开配置面板，省去手动点开的一步。
- 方案名称与描述支持行内编辑，重命名不用再进二级弹窗。
- 自定义配置方案不再因加载时序问题丢失。
- 方案保存后强制立即写入数据库，重启后自定义方案仍在。
- 内置方案可以复制后再编辑，改坏了也能随时回到原样。
- 梦幻皮肤支持 GIF 与视频作为背景。
- 动态背景支持永久声音 / 仅首次声音 / 静音三种音频模式，并可调节音量。

## 变更（自上一版本以来）

### 新增

- 梦幻皮肤支持 GIF 和视频背景，并提供三种音频模式（永久声音 / 仅首次声音 / 静音）与音量滑轨控制。
- 配置方案编辑模式新增名称和描述的行内编辑。
- 内置方案支持复制后编辑。

### 改进

- 配置方案弹窗改用 Portal 渲染，从根本上修复遮挡问题。
- 新建方案时自动展开配置面板，配置流程更连贯。

### 修复

- 修复自定义方案重启后丢失：ModelProfile 单例的 load() 在 initDatabase 之前执行，现改为数据库初始化完成后 reload。
- ModelProfile save() 之后调用 flushDatabase 强制立即写入，避免配置方案未能落盘。

> 改动规模：12 files changed, 295 insertions(+), 25 deletions(-)
