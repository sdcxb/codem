# Codem v0.94.0

**发布日期**：2026-08-03
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.94.0` 构建。

## 本版要点

- 配置方案Portal渲染彻底修复遮挡
- 新建方案自动展开配置面板
- 名称描述行内编辑
- 持久化修复(ModelProfile单例在DB初始化后reload)
- 梦幻皮肤支持GIF和视频背景(3种音频模式
- 音量滑轨)

## 变更（自上一版本以来）

- 配置方案Portal修复+持久化修复+梦幻皮肤GIF/视频背景
- 梦幻皮肤支持GIF和视频背景 — 3种音频模式(永久声音/仅首次声音/静音)+音量滑轨控制
- ModelProfile单例在DB初始化后reload — 根因是load()在initDatabase前执行导致自定义方案丢失
- ModelProfile save()后flushDatabase强制立即写入，防止重启丢失自定义方案
- 配置方案编辑模式新增名称和描述的行内编辑

## 升级说明

- 覆盖安装即可；数据与设置保存在应用数据目录，升级不需要迁移。

## 校验

- 本版未留存安装包与更新器签名（历史版本）。
