# Codem v0.80.2

**发布日期**：2026-07-15
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.80.2` 构建。

## 本版要点

- 新增回答显示模式切换（分段 / 统一），统一模式为默认：所有迭代合并到一个气泡，reasoning 默认折叠、工具调用合成一个列表。
- 修复统一模式下子智能体等待调用反复重复、主任务无法继续的问题。
- 增强任务完整性检查：要求「追加 / 输出到 / 写到」文件时会正确触发写入检查，要求汇总结果并写入时还会追加提醒。
- 调整显示模式按钮位置，移到上下文监控按钮旁并高亮当前模式。
- 本版共改动 16 个文件、新增 365 行、删除 41 行。

## 变更（自上一版本以来）

### 新增

- 新增回答显示模式切换（分段 / 统一），在 ChatPanel 顶部提供切换按钮；数据库仍按分段方式每轮独立存储，统一模式在渲染层把连续的回复合并为一个气泡。
- 新增 `displayMode` 状态与设置项，并把统一模式设为默认值。
- 新增显示模式相关的中英文案，用于模式名称与提示说明。

### 改进

- 统一模式下 reasoning 面板与工具调用默认折叠、各迭代之间以细分隔线区分。
- 显示模式按钮从最右侧移到上下文监控按钮旁，当前模式高亮显示，并统一使用既有按钮样式。
- 更新界面测试用例以匹配显示模式改动。

### 修复

- 修复统一模式下子智能体等待调用无限重复的问题：统一模式改回每轮创建独立消息以保证上下文清晰，单次响应去重增加跨迭代缓存检查，新增缓存命中计数，并在全部工具调用均为缓存命中时触发停止条件。
- 增强任务完整性检查：写入意图识别补齐「追加 / 输出到 / 写到」等关键词；新增汇总意图检查，当用户要求汇总或合并结果并写入文件而未执行写入时注入额外提醒。
- 修复任务在收集完子智能体结果后停止、未执行文件写入的问题。

> 改动规模：16 files changed, 365 insertions(+), 41 deletions(-)
