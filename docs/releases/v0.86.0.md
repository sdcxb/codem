# Codem v0.86.0

**发布日期**：2026-07-20
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.86.0` 构建。

## 本版要点

- 新增皮肤系统，提供默认、Hub、梦幻三套皮肤，可在设置面板中切换并持久化。
- 窗口毛玻璃效果：关闭系统默认装饰，接入 Mica/Acrylic（Windows）与 vibrancy（macOS）。
- 新增自定义标题栏组件，支持拖拽窗口与窗口控制按钮，并适配三套皮肤。
- 新增梦幻皮肤配置面板，可调节背景上传、毛玻璃、装饰与拍立得等选项。
- 新增 Canvas K-Means 颜色提取器，可从图片中提取配色生成皮肤色板。
- 修复 Hub 皮肤的消息双边框与右侧栏响应式问题，优化梦幻皮肤的设置面板磨砂与技能弹窗毛玻璃。
- 默认皮肤背景改为完全不透明，只有标题栏透出 Mica。
- 清理 `.wecode-ref` 并修复 `.gitignore`，测试总数 1482 个全部通过。

## 变更（自上一版本以来）

### 新增

- 新增皮肤系统，提供默认 / Hub / 梦幻三套皮肤预设，以及梦幻皮肤的色板预设。
- 新增 `src/core/theme/` 主题模块，包含 `SkinId`、`SkinConfig`、`DreamSkinConfig`、`ExtractedPalette` 等类型定义。
- 新增主题管理器 `theme-manager.ts`，负责皮肤切换、持久化与 CSS 变量注入。
- 新增 Canvas K-Means 颜色提取器 `theme-extractor.ts`，用于从图片提取配色。
- 新增 `SkinSelector.tsx` 皮肤选择器组件，以卡片形式选择三套皮肤。
- 新增 `DreamConfigPanel` 梦幻皮肤配置面板，支持背景上传、毛玻璃、装饰、拍立得等设置。
- 新增自定义标题栏 `TitleBar` 组件，支持窗口拖拽与窗口控制按钮，并适配三套皮肤。
- 窗口毛玻璃：采用 `decorations: false`，在 Windows 上接入 Mica/Acrylic，在 macOS 上接入 vibrancy。

### 改进

- 皮肤选择器集成到 `SettingsPanel`，替换原有明暗模式选择。
- `App.tsx` 初始化 ThemeManager，`styles.css` 补充皮肤选择器与梦幻配置面板样式。
- 默认皮肤背景改为完全不透明，只有标题栏透出 Mica。
- 梦幻皮肤优化设置面板磨砂效果与技能弹窗毛玻璃。

### 修复

- 修复 Hub 皮肤的消息双边框问题。
- 修复 Hub 皮肤右侧栏的响应式问题。
- 清理 `.wecode-ref` 目录并修复 `.gitignore`。

> 改动规模：44 files changed, 4773 insertions(+), 1018 deletions(-)
