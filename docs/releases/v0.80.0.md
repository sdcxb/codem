# Codem v0.80.0

**发布日期**：2026-07-14
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.80.0` 构建。

## 本版要点

- 分叉与重新生成改为按问答轮次整体操作：分叉以整轮问答为单位派生新会话，重新生成会整轮重跑，不再只处理单个消息段落。
- 修复界面元素对比度问题，深色/浅色模式下原本看不清的按钮与提示文字恢复可读。
- 优化长对话滚动性能，屏外消息不再参与渲染计算，已完成的回复不会反复重渲染。
- 修复会话置顶：置顶状态可以持久化到数据库、正确排序，快速连点也不会错乱。
- 修复记忆系统在数据库初始化前加载导致内容为空的问题。

## 变更（自上一版本以来）

### 新增

- 新增按轮次的分叉（fork）与重新生成操作：分叉按钮只出现在用户提问消息上，点击后复制从开头到当前轮次结束的全部消息到新会话；重新生成按钮只出现在轮次中最后一条回复上，会从该位置向上找到用户消息，删除该用户消息之后的整轮回答并重新执行。
- 会话数据新增 `pinned` 字段与 `sessions` 表的 `pinned` 列（含自动迁移），置顶状态开始纳入持久化。
- 新增 `SessionStorage.togglePinned(id)` 原子切换方法，直接从数据库读取当前真实值。
- 新增测试覆盖共 49 个用例，覆盖轮次末尾判定、整轮分叉、整轮重跑、按钮显示条件与边界情况，全部 166 个测试通过。

### 改进

- 消息列表按完整问答轮次分组并加入细分割线，不同轮次在视觉上清晰区分，悬停时显示分叉与重新生成按钮。
- 新增 `--text-on-accent: #ffffff` 语义变量，统一所有强调色按钮的文字颜色。
- 滚动性能优化：使用 CSS `content-visibility: auto` 跳过屏外消息渲染、`contain: content` 限制重排范围到单个消息气泡。
- 用 `React.memo()` 包装 `MessageBubble`，已完成的回复不再因父组件状态变化而重渲染；缓存 ReactMarkdown 的 `components` 配置，避免 Markdown 重复解析。
- 统一记忆系统与 MCP 管理的按钮样式，并把 ➕/📥/📝/📤/🧹 等 emoji 换成纯文本；ContextMonitor 的 🗜️ 换成 `▼`（该 emoji 在 Windows 上渲染为紫色，深色模式不可见）。
- 会话列表查询改为 `ORDER BY pinned DESC, last_message_at DESC`，置顶会话稳定排在前面；置顶图标在 📌/📍 之间切换。

### 修复

- 修复界面中引用不存在的 CSS 变量导致的问题：`--accent-primary` → `--accent`、`--text-error` → `--error`、`--border-color` → `--border-primary`。
- 修复 `.agent-toggle.active` 紫字紫底、`.mode-toggle-btn` 缺少颜色属性导致深色模式按钮不可见、`.compaction-banner.compaction-active` 文字颜色异常，以及设置面板会话恢复/用量统计按钮白字浅底不可见的问题。
- 修复置顶按钮点击后没有切换逻辑的问题；修复取消置顶时 `lastMessageAt` 被强制刷新导致会话跳到顶部的问题；修复快速连点时闭包捕获旧值造成的状态错乱。
- 修复记忆系统单例在数据库初始化前创建、导致打开记忆管理器时数据为空的问题。
