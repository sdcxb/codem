# Codem v0.79

**发布日期**：2026-07-13
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.79` 构建。

## 本版要点

- 引入三级安全策略，按层级约束高风险操作。
- 提升 LLM 连接稳定性，减少长任务中的连接中断。
- 提升任务完整性，降低任务中途丢步的概率。
- 修复智能体协作环节的问题。
- 新增确定性步骤进度显示，任务进展更可预期。
- 提供 Codex 风格的子智能体执行视图，便于观察子任务运行。
- 完善双语 UI、系统托盘、关闭窗口行为、安装包语言选择器与终端能力。
- 修复思考过程显示与工具调用顺序问题，并做了一轮性能优化。
