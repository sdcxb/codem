# Codem v0.60

**发布日期**：2026-07-03
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.60` 构建。

## 本版要点

- 系统提示词全面重写，明确助手的身份定位、性格设定、价值取向、输出格式与安全边界。
- 新增搜索对话框，为界面提供独立的检索入口。
- 支持把项目固定在列表中，方便随时回到常用项目。
- 消息列表改为懒加载，长会话下滚动更轻快。
- 校正 v0.56 更新日志中的已知问题描述。
