# Codem v0.55

**发布日期**：2026-07-03
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.55` 构建。

## 本版要点

- 新增推理过程可视化，可以看到模型在给出答案前的推理内容。
- 新增文件清理按钮，一键清理会话过程中产生的文件。
- 生成文件（generated_files）记录持久化保存，会话之间不再丢失。
- 修复 Bash 工具输出截断问题，Rust 侧截断改为 UTF-8 安全切分，不再出现截断错误或乱码。
- 消息加载与保存增加错误处理，读写异常不再直接中断。
- 文档补充多智能体界面截图并更新变更日志。
