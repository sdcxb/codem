# Codem v1.18.10

**发布日期**：2026-11-06
**类型**：Android 本机模式预览
**下载**：Android 本机模式见下方；Windows 安装包随版

## 本版要点

**手机本机模式开始按「本地开发常态」补齐**：

1. **项目工作区持久化**：手机本机 Host 的项目目录从打包的 web 资源目录迁到应用持久数据目录 `files/data/workspace`，Host 重启、升级、重建都不会覆盖用户项目。
2. **项目选择/新建**：原生「本机模型设置」增加「项目工作区」区域：
   - 显示当前工作区路径；
   - 「选择项目工作区」列出已有项目目录；
   - 「新建项目目录」直接创建并切换；
   - 保存后重启本机 Host，`--workspace` 指向所选项目。
3. 欢迎会话文案改为提示手机本机模型设置，不再说「模型与凭据在桌面端配置」。

## Android 本机模式

- `Codem-Shell-1.18.10-arm64.apk`：真机安装包，APK 内含 PRoot + Ubuntu + Node + 本机 Host，不依赖电脑。
- `Codem-Shell-1.18.10-x86_64.apk`：x86_64 模拟器包。
- 当前为 debug 签名预览包，只用于真机验证。

## 使用

1. 安装 APK，首次启动等待运行时解压；
2. 点顶部「信息 → 本机模型设置」；
3. 填模型服务地址与 `sk-acw-*` Key，点「使用 AI Code With 预设」「获取模型列表」，选模型；
4. 在「项目工作区」新建或选择项目，点「保存」；
5. Host 重启后，对话与工具就在该手机项目目录里工作。

## 升级说明

- 覆盖安装保留 `files/data` 下的会话与项目；旧工作区（web 资源目录）不再作为项目根。
- 已保存的 Key 保留；工作区选择重新点一次即可。

## 已知问题 / 后续

- 手机外部存储（相册/下载目录）的项目导入、系统文件选择器、终端还未接；
- 当前本机 UI 复用 Host 共享 Web UI，原生项目管理只覆盖「选择/新建目录」；
- Flutter 远程客户端仍是「手机看电脑」形态，不是本机运行。
