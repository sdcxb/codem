# Codem v0.96.2

**发布日期**：2026-08-11
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.96.2` 构建。

## 本版要点

- 集成 CodeGraph 代码知识图谱，项目结构可以被检索和引用。
- 自动检测项目中的 .codegraph/ 目录，无需手动配置即可启用。
- 检测到知识图谱后自动注册为 MCP Server，供对话过程调用。
- 同时把图谱信息注入系统提示词，模型回答时自带项目结构上下文。
- 设置页面新增 CodeGraph 标签页，可在界面中查看和管理集成状态。
- 测试套件从表面断言改造为真实行为验证：去掉读源码字符串比对的写法，直接验证模块行为。
- 新增 CI Workflow，推送即执行 tsc 类型检查、vitest 测试与 cargo check。
- 新增 CodeGraph 集成测试 49 个用例，覆盖 4 层链路。

## 变更（自上一版本以来）

### 新增

- CodeGraph 代码知识图谱集成：自动检测 .codegraph/ 目录、注册 MCP Server、注入系统提示词，并在设置页面提供标签页。
- 新增 CodeGraph 集成测试，49 个用例覆盖 4 层。
- 新增 CI Workflow，包含 tsc 类型检查、vitest 测试与 cargo check。

### 改进

- 测试套件改造：把 readFileSync + toContain 这类源码字符串比对，改为对真实模块行为的验证。
- 修复 Vite watch 相关问题，开发时的文件监听更可靠。
- 应用图标整体替换为 codem.ico，安装包与快捷方式 logo 全套更新（ICO / ICNS / PNG）。

### 修复

- 文件拖拽失效与拖拽方向反转：调整 Tauri dragDropEnabled 与 dropEffect。
- 右侧栏文件浏览器在 Hub 皮肤下显示异常，改为强制暗色。
- TitleBar 主题初始化时机不对导致的外观不一致。
- MentionAutocomplete 重写，提及补全不再出错。
- 文件编辑器改为悬浮窗口并通过 createPortal 全屏预览，补齐图片 / PDF / Excel / Word / 视频 / 音频 / HTML 全格式预览。

> 改动规模：95 files changed, 4438 insertions(+), 1959 deletions(-)
