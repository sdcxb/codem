# Codem v0.79.9

**发布日期**：2026-07-14
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.79.9` 构建。

## 本版要点

- 修复界面元素对比度不足的问题。
- 统一按钮样式与交互表现。
- 建立设计系统基础：引入 Radix UI 组件、重构 CSS 变量、启用紫色强调色，并定义阴影、圆角、层级等设计令牌。
- 消息气泡新增工具栏，支持长消息折叠与流式输出动画。
- 侧边栏支持拖拽调整宽度与右键菜单，会话可分管理，输入区域可展开收起。
- 新增文本选中提示气泡与引用上下文，并建立全局提示气泡体系。
- 新增 97 个界面回归测试，覆盖本轮界面优化。

## 变更（自上一版本以来）

### 新增

- 设计系统基础：引入 Radix UI 组件，重构 CSS 变量，启用紫色强调色，并定义阴影、圆角与层级（z-index）设计令牌。
- 消息气泡工具栏：在消息气泡上提供操作工具栏。
- 长消息折叠：过长的消息可折叠显示，便于浏览。
- 流式输出动画：消息流式生成过程中带有动画提示。
- 侧边栏宽度拖拽：可手动调整侧边栏宽度。
- 侧边栏右键菜单：提供右键上下文菜单。
- 会话分组：支持对会话进行分组管理。
- 输入框展开与收起：输入区域可展开与收起。
- 文本选中提示气泡：选中文本后弹出操作提示。
- 引用上下文：支持把选中的文本作为引用上下文使用。
- 全局提示气泡体系：统一全应用的气泡提示组件。
- 界面回归测试：新增 97 个回归测试，覆盖本轮界面优化。

### 改进
