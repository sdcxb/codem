# Codem v1.16.311

**发布日期**：2026-10-12
**类型**：稳定版（Windows x64）
**下载**：`Codem_1.16.311_x64-setup.exe`（NSIS 安装包）· `Codem_1.16.311_x64_en-US.msi`（MSI）

## 本版要点

1. **内置免费模型插件，现在整条链都通了** —— 上一版把开源项目 **Our Free Model** 内置进来（装好即用、默认开启、
   不需要登录或 API Key），这一版修掉了它落地时暴露的几处问题：
   - **选中免费模型后对话报错**（`openai not configured`）：模型是插件提供的，但"该用哪家供应商"仍按老配置推，
     推不出来就落到 `openai` ⇒ 请求发错地方、这一轮根本没发出去。现在**按模型归属自动判定**：模型属于插件
     就走插件的本地网关（密钥由插件自己注册，你什么都不用配）。
   - **模型管理里选得着免费模型了**：那个下拉原来只列"配了 Key 的供应商"，而插件这条**故意不落盘密钥**
     ⇒ 免费模型根本不在列表里；现在照实列出，而且**选中即生效**。
   - **插件卡片上的『刷新模型列表』真的能刷**：它原来被"必须有 Key"的闸挡住；放行之后又发现那个本机服务
     **确实要 Key**（不带就 401），现在从插件运行时配置取，实测能刷出**真实的 25 个模型**（不是内置兜底）。
   - **不会再"一会儿有、一会儿没有"**：模型清单的缓存原来 60 秒过期却没人续 ⇒ 跑过一分钟列表里就空了；
     现在启用期间每 45 秒自动续一次。
   - **上游模型不可用时说人话**：免费池里个别模型会临时不可用（端点挂了 / 上游账号限制 / 不支持该协议），
     以前只把上游原文甩给你；现在会说明**这是上游侧的问题**、点名是哪个模型，并建议**换一个免费模型**再试。
2. **修掉设置里的"紫框套紫框"**：聚焦下拉或输入框时，外层容器也画了一圈，控件自己还有一圈
   （而且是浏览器默认色）⇒ 又挤又花。现在**一个焦点目标只画一个环**，统一用主题色；编辑框额外叠的那层也去掉了
   （它本来就有自己的内嵌环）。键盘可达性不受影响 —— 焦点环还在，只是不再重复。

## 变更

### 新增
- 上一版起内置 **Our Free Model** 的本地服务（OpenAI 兼容：`/v1/models`、`/v1/chat/completions`，含流式），
  随安装包提供并按固定版本 + 逐文件校验；不想要可在「插件管理 → 插件市场」里**暂停**或**删除**。

### 修复
- 选中内置免费模型后对话报 `openai not configured`（发消息前的供应商判定改为按模型归属）。
- 免费模型不在"模型管理"的可选列表里；选中后不立即生效。
- 插件卡片的『刷新模型列表』不可用（先是"要求 Key"，后是"取不到列表"）。
- 免费模型过一分钟后从模型列表里消失。
- 上游免费模型不可用时的提示不可操作。
- 设置里的选择框/编辑框出现双层或过粗的紫色焦点框。

## 对标结果

**本版未重跑对标评测**，沿用上一稳定版的结论：在 **12 个真实仓库修复任务**上，本版通过 **10 个**，
参考实现（DSH，同一套任务、同一模型）通过 **9 个**；完成同样任务所需的工具调用约为参考实现的一半，
输出 token 用量明显更少；单次响应时延仍慢于参考实现（取决于模型服务端，客户端侧不是瓶颈）。

本版改动集中在"内置免费模型插件的落地修复"与"设置界面的焦点环"，没有触碰 agent 循环与工具链路。

## 升级说明

- 覆盖安装即可；已有的会话、记忆、待批准条目、供应商与设置原样保留。
- 如果你上一版已经配好了免费模型插件，本版装上后**不需要重新配置**：到设置里选一个免费模型直接对话即可
  （推荐先在插件卡片上点一次『刷新模型列表』）。
- 免费池由上游免费提供，可用性和速度会波动；个别模型可能临时不可用 —— 换一个 `-free` 模型即可。

## 已知问题

- 免费池是**第三方公开网关**（不是 Codem 的服务器），其模型卡里声明"提示词可能被记录用于改进服务"
  —— **请不要用它发送敏感内容**。
- 免费池里"可用 / 地区受限"是上游给的属性，且会随时间变化；个别模型会返回
  `Model does not support this protocol.`，属上游对该模型的限制。
- 如果 Codem 是被**任务管理器强制结束 / 断电**而不是正常退出，会留下一个插件进程占着端口；
  插件会自己换端口继续工作（功能不受影响），正常退出时会一起收掉。
- 模型清单里的免费模型来自上游实时列表，**上游改了就跟着变**，这是预期行为。

## 校验

- 附更新器签名 `.sig`；`latest.json` 平台键为 `windows-x86_64-nsis` 与 `windows-x86_64`（同一份签名）。
- 安装包 sha256 与更新器清单一致（可用仓库内 `tools/release/verify-update-manifest.mjs --remote` 复核）。
