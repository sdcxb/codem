- 会话管理（SessionManager）迁移到 SQLite，会话与消息数据统一由 SQLite 数据库存储。
- 会话的加载与保存随迁移统一走 SQLite 存储路径。
- 修复系统提示词中的身份信息错误，提示词里的身份描述恢复正确。
- 统一版本号，应用各处的版本标识一致。
- 本版共改动 11 个文件、新增约 381 行代码，是一次以存储层为主的中等规模更新。
