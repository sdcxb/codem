# Codem v0.52

**发布日期**：2026-07-02
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.52` 构建。

## 本版要点

- 引入多智能体（multi-agent）系统，多个智能体可以参与同一任务的协作。
- 新增系统提示词（system prompt）能力，为智能体设定统一的角色与行为。
- 对话输出自动滚动，新内容到达时视图自动跟随到最新位置。
- 流式输出优化，模型回复边生成边显示，等待时间更短、渲染更平滑。

## 变更（自上一版本以来）

### 新增

- 多智能体（multi-agent）系统：应用开始支持多个智能体参与任务处理。
- 系统提示词（system prompt）支持：为智能体提供统一的角色与行为设定。

### 改进

- 对话输出自动滚动：新内容到达时视图自动跟随，不需要手动拖到底部。
- 流式输出优化：模型回复在生成过程中即时显示，长回答的等待时间缩短。
- 流式渲染性能优化：输出过程中界面保持流畅，回复渲染更平滑。
