# Codem v1.16.316

**发布日期**：2026-10-13
**类型**：稳定版（Windows x64）
**下载**：`Codem_1.16.316_x64-setup.exe`（NSIS 安装包）· `Codem_1.16.316_x64_en-US.msi`（MSI）

## 本版要点

1. **模型列表不再"少一半"**（这次是真问题）
   - 实测发现：插件接口当时提供 **26 个**免费模型，而界面里的模型列表**只有 12 个**（少了包括
     `mimo-v2.6-flash-free` 在内的常用项）—— 原因是列表只读了**内存缓存**，而那份缓存是较早一次
     刷新时建立的短列表，在缓存有效期内界面就一直显示它。
   - **现在**：列表取**"内存缓存 ∪ 落盘动态列表"的并集**（两者都是服务器真实列出来过的模型），
     并自动去重 ⇒ 任何一侧偏短都不会再把模型整批藏起来。
2. **模型列表的模态标注：【多模态】/【文本】/【未知】**
   - 依据来自插件自己的目录里 `vision: true|false` 的**权威布尔值**；
   - **没有依据的一律标【未知】—— 不用名字猜**（名字里带 vl/vision 不代表任何确定信息）；
   - 已标在**六处**列表：设置里的三条渲染分支、对话里的模型选择器、档案面板、ModelSelector。
3. **模型列表的三处体验问题**
   - **换行严重** ⇒ 下拉放宽（按内容撑开，320px 下限 / 560px 上限），选项一行放完；
   - **长名难读** ⇒ 过长用省略号截断，**鼠标悬停显示完整模型名**；
   - **太长遮住下面** ⇒ 下拉限高（约 52vh / 420px）并自己滚动；
   - **点别处不收起** ⇒ 点任何非本下拉的地方（包括「设置」按钮）都会自动收起。
4. **提示不再指向找不到的按钮**：原来的"点插件卡片上的『检测可用性』"改成"点上面的【刷新模型列表】
   会重新检测" —— 刷新之后本来就会在后台自动补测。

## 变更

### 新增
- 模型列表的三态模态标注（【多模态】/【文本】/【未知】）。

### 修复
- 模型列表比插件实际提供的少（现在取并集，不再被短缓存藏掉）。
- 下拉换行严重 / 太长遮住下方面板 / 点其它按钮不收起。
- 「关于」与内置示例插件里的旧名称。

## 对标结果

**本版未重跑对标评测**，沿用上一稳定版的结论：在 **12 个真实仓库修复任务**上，本版通过 **10 个**，
参考实现（DSH，同一套任务、同一模型）通过 **9 个**；完成同样任务所需的工具调用约为参考实现的一半，
输出 token 用量明显更少；单次响应时延仍慢于参考实现（取决于模型服务端，客户端侧不是瓶颈）。

本版改动集中在免费模型插件的列表呈现与文案，没有触碰 agent 循环与工具链路。

## 升级说明

- 覆盖安装即可；已有的会话、记忆、待批准条目、供应商与设置原样保留。
- 如果你还停在 1.16.310 / 1.16.311：升级时可能弹出「无法打开要写入的文件：…\resources\node\node.exe」，
  遇到时请**先完全退出 Codem 再装**，或点 **[Ignore]**（别点 [Retry]）；装到 1.16.313 之后不会再被挡。
- 想看哪些免费模型当前可用：点插件卡片上的「检测可用性」（在 **插件管理 → Our Free Model** 卡片上），
  或直接点【刷新模型列表】（现在会自动检测）。

## 已知问题

- **模态标注的"未知"是诚实的结果，不是缺陷**：上游目录只给一部分模型提供了模态信息，
  其余显示【未知】—— 我们不用名字猜。想变确定需要**实测**（发一张极小图片看接口是否接受图像输入）。
- 「不可用」是带时间戳的结论：超过 30 分钟自动失效（上游可能已恢复），隐藏的模型会自己回到列表。
- 免费池是**第三方公开网关**（不是 Codem 的服务器），其模型卡里声明"提示词可能被记录用于改进服务"
  —— **请不要用它发送敏感内容**；上游模型随时上下线，属预期。
- 退出时的「卡一下/要按两次」：此前已把退出路径上的同步等待改成"发出去不等"（有判据与变异守着），
  但**尚未在真机上完成端到端计时确认** —— 如仍遇到请反馈现象。

## 校验

- 附更新器签名 `.sig`；`latest.json` 平台键为 `windows-x86_64-nsis` 与 `windows-x86_64`（同一份签名）。
- 安装包 sha256 与更新器清单一致（可用仓库内 `tools/release/verify-update-manifest.mjs --remote` 复核）。
