# Codem v0.87.0

**发布日期**：2026-07-24
**类型**：稳定版（Windows x64）· 历史版本
**安装包**：本版为 1.0 之前的历史版本，发布资产未留存；如需可从源码按 tag `v0.87.0` 构建。

## 本版要点

- 新增 Git Worktree 全链路：会话可运行在独立工作树中，输入区可切换本地/工作树模式并选择分支，删除与派生会话时自动清理或新建工作树。
- 并行对话隔离：多个会话可同时流式输出、同时执行工具，权限确认、写确认、交互式表单互不串扰。
- 新增自动任务系统：按定时器或文件变化触发提示词，可在设置中可视化配置并查看触发历史。
- 新增 GitHub Clone：在项目管理器中直接填入 git clone 地址即可拉取远程仓库并创建项目，三套皮肤均可用。
- 新增全局字体系统：内置 Alimama 方圆体变量字体，设置中可选全局字体并连续调节 100–900 字重，实时预览。
- 侧边栏布局重构：设置与搜索按钮移入标题栏，MCP/技能/记忆改为分段控件，项目区与全局对话区各自独立滚动。
- Prompt Cache 优化：系统提示词时间戳由毫秒精度降为分钟精度，同一分钟内多次迭代的 KV Cache 命中率明显提升。
- 新增 Git 信息面板与 Git 环境设置：集中查看分支、脏文件、diff、提交与推送拉取状态，并配置令牌、提交身份与脚本。

## 变更（自上一版本以来）

### 新增

- Git Worktree 管理能力：支持创建、移除、扫描工作树并设默认上限（超出按最近最少使用清理），兼容 Windows PowerShell。
- 环境运行器：按配置自动执行工作树的 setup 与 cleanup 脚本；会话记录中新增工作树路径、执行模式与工作树分支字段。
- 自动任务管理器：支持定时器与文件监听两类触发器，含配置增删改查、启动/触发/停止、全部停止与触发历史。
- GitHub Clone：项目管理器新增拉取入口，四个操作按钮改为 2×2 网格布局，拉取对话框三套皮肤通用。
- Git 信息面板：集中展示分支、脏文件、diff、提交、推送/拉取与工作树状态。
- Git 环境设置页：支持配置访问令牌、提交身份与脚本，设置面板新增 Worktree 分类。
- Slash 命令菜单：输入 `/` 唤起的命令菜单。
- 全局字体系统：内置 Alimama 方圆体变量字体文件，设置 → 通用新增全局字体下拉选择，设置 → 外观新增 100–900 字体粗细滑块并实时预览，可切换 Inter、系统默认、Courier New、Georgia 等字体。
- 并行执行基础设施：活跃会话改为按会话标识的集合，迭代循环改为按会话标识的循环池，所有基于 Promise 的交互界面改为按会话存放。
- 性能优化专题：系统提示词时间戳精度由毫秒降到分钟，减少同分钟内重复前缀变化带来的缓存失效。
- 外观适配：MCP/技能/记忆分段控件用 `color-mix` 结合主题强调色自适应，三套皮肤下均保持对比度。

### 改进

- 侧边栏布局重构：设置与搜索按钮移至标题栏右侧，释放导航区域空间；MCP/技能/记忆改为 iOS 风格分段控件与紧凑三列布局。
- 滚动行为改善：全局对话超过 3 条时内部滚动，项目区域独立滚动，不再与全局对话共用滚动条。
- 项目管理器的更多操作菜单改用 Portal 渲染，不再被容器 overflow 裁剪。
- 选择项目时自动打开该项目的最新会话。
- 设置面板默认打开「通用」分类，不再残留上次停留的分类。
- 全部弹窗（确认、权限、提示词变更复核、交互式表单、搜索、关闭确认）改用 Portal 渲染到 body，绕过梦幻皮肤磨砂玻璃造成的定位问题。
- 安全移除项目：改为三按钮确认（移除 / 删除到回收站 / 取消），删除走系统回收站而非直接抹除。
- 设置侧边栏调整为 9 个分类（通用/外观/安全/Git/环境/Worktree/知识/自动化/多模态）。

### 修复

- 修复 TypeScript 编译错误：上下文配置的私有成员访问、权限请求类型定义、子智能体派发接口三处对齐。
- 修复 v0.86 更新日志中的图片路径：GitHub Release 页面不解析相对路径，改为绝对链接。
