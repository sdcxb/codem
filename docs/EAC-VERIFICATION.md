## 功能验证清单

### 1. 编辑并回退（对标 dsh-message-rewind）
- 开一个会话，至少产生 2 轮对话
- hover 一条**历史** user 消息 → 工具条出现两个按钮：✏️（编辑并重发，Pencil）与 ↩（编辑并回退，Undo2）
- 点 ↩ → 修改文本 → 保存
- **预期**：自动新建 `Rewind: <原标题>` 会话并在其中重放（从该消息之前的上下文开始），原会话消息一条未删
- 点 ✏️ → 行为保持旧语义（就地删除后续 + 重发）

### 2. 节点导航升级 + 消息精选 pin（对标 dsh-navbar）
- 长会话滚动后：对话右缘出现圆点导航条
- **预期修复**：滚动时圆点位置实时跟随（旧版绑定错误容器不动）
- hover 圆点 → 出现消息预览卡；在导航条上滚轮 → 在 user 消息间循环跳转
- hover 一条 assistant 消息 → 点 📌（Pin）→ 导航条出现**金色圆盘**，点击直达该消息；再点取消
- 精选状态按会话保存（切换会话再回来仍在）

### 3. 输入框失焦折叠（对标 meow-smooth）
- 输入框输入多行（含换行）→ 点击对话区其它位置（失焦）
- **预期**：输入框收成单行胶囊（150ms 过渡）
- 点击输入框 → 立即展开并恢复多行内容

### 4. 字号设置生效（D1）
- 设置 → 外观 → 字号滑杆拖到 18px
- **预期**：界面字号**即时变化**（旧版无效）；重启后保持

### 5. 设置搜索（D2）
- 设置页顶部搜索框输入"字体"或"font"
- **预期**：自动跳转到「外观」分组，下方出现"已跳转至「外观」"提示；输入乱串显示"未找到匹配"

### 6. persona 人设卡（B2）
- 设置 → 「人设」tab → ＋ 新建：名称 + 内容（如"你是资深 Rust 工程师，回答精炼"）→ 保存 → 点 ✓ 激活
- 新开一个会话随便问 → **预期**：模型按人设风格回答（系统提示已注入 `# Persona`）
- 编辑该卡改内容 → 新会话生效（热重载）
- 也可用"外部文件路径"模式指向一个 .md，改文件即热重载
- 在「插件 → 管理」禁用 @codem/persona → 新会话不再注入（门控生效）

### 7. 临时会话 side-session（B1）
- 对话 header（顶部按钮区）点 💬（临时会话）
- 悬浮窗出现（右下角、可拖标题栏）
- 当前会话随便聊几句后，在悬浮窗输入"刚才我们讨论了什么？总结一下"
- **预期**：基于当前会话上下文流式回答（逐字出现——验证 text_delta 修复），**主会话不新增任何消息**
- 关窗重开 → 临时会话记录丢弃（不污染主会话）

### 8. 团队 agent-teams（B3）
- 对话 header 点 👥（团队活动）→ 面板提示"本会话还没有活动团队"
- 对助手说："建一个团队，研究员先调研 X 的 API 用法，工程师再基于结果写示例代码，最后汇总"（X 可换任意主题）
- **预期**：助手调用 agent_teams_create → add_member → create_task（t1 调研 / t2 实现依赖 t1）→ 面板实时显示成员与任务状态流转（pending→claimed→in_progress→completed）
- 完成后面板保留任务历史；点 👥 关闭
