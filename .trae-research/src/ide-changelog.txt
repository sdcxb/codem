2026 年 10 月 08 日（功能发布）
TRAE v3.4.0 版本正式发布。以下是变更细节：
上线 Agent 窗口。Agent 窗口是一个以 Agent 为中心的全局工作台，一个窗口跨项目调度多个智能体，支持发起云端任务、定时任务，代码、文档、PPT、图片视频等产物统一汇总管理。Agent 窗口和 IDE 窗口之间可以随时自由切换、数据同步。详情参考 Agent 窗口快速开始 。
支持在 Agent 窗口中直连远端开发机目录作为工作目录，远端环境里运行任务。详情参考 使用 SSH 进行远程开发 。
支持一个项目同时挂载多个路径，任务按项目分组管理，文件树和全局搜索跨项目打通，更方便地进行多仓库开发。
提供桌面常驻对话悬浮球，不用打开主窗口就能随时发起任务、查看智能体的工作进度。详情参考 桌面悬浮球 。

2026 年 04 月 14 日（功能发布）
TRAE CN v3.3.51 版本正式发布。以下是变更细节：
优化了 RunCommand 工具的执行。
优化了规则功能：
支持规则嵌套 ：你可以在 .trae/rules/ 目录下创建子文件夹来对规则进行分类。系统会自动递归读取最多 3 层的规则目录。详情参考 关于多层规则嵌套 。
支持为子目录创建规则 ：你可以在项目内任一子目录下创建 .trae/rules/ 文件夹，以便为该模块配置专属规则。当你在对话中提及该目录下的文件，或 AI 读取这些文件时，系统将自动应用这些规则。详情参考 关于为子目录创建规则 。
增加 Git Commit Message 生成规则的配置入口：
在 “源代码管理” 面板的下拉菜单中，点击 “配置提交信息生成规则” 后可打开规则文件，你可以在该文件中配置 Git Commit Message 生成规则。
首次使用 AI 生成 Git Commit Message 功能时，系统会弹出规则配置提示。
详情参考 为提交内容（Git Commit Message）设置规则 。
MCP Server 支持完整的 OAuth 授权流程，包括授权、运行、调用和解除授权。
支持为自定义模型配置自定义请求地址。
