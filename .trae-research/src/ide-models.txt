 内置模型 & 自定义模型
 复制页面
TRAE 内置多款主流模型，你可以根据实际任务灵活切换使用。除内置模型外，TRAE 还支持接入自定义模型。

切换模型
在 AI 对话输入框的右下角，点击当前模型名称，打开模型列表，然后选择你想使用的模型。各个模型的能力不同，你可以将鼠标悬浮至模型名称上，然后查看该模型支持的能力。
添加自定义模型
如果内置模型无法满足需求，你可以添加自定义模型。可用的模型来源如下：
模型服务商 ：从 TRAE 预设的模型服务商和模型列表中选择，按界面提示填写 API 密钥即可添加。
自定义配置 ：通过配置 API 格式、请求地址、模型 ID 和鉴权信息，接入 TRAE 未预设的模型。
添加自定义模型的步骤如下：
在 IDE 窗口或 Agent 窗口中，前往 设置 > 模型 。
你已进入模型管理面板。
点击 添加模型 按钮。
界面中出现 添加模型 窗口。
选择 TRAE 预设的模型服务商或选择 自定义模型 选项。
完成基础模型配置。
若你选择了预设的模型服务商，则需配置以下参数：

服务商 | 
 已默认设置为你在上一步中选择的模型服务商。你可以按需切换。 |

Coding Plan ：使用该服务商面向编码场景提供的套餐额度。
Agent Plan ：使用该服务商面向 Agent 场景提供的套餐额度。

API 格式
|
设置模型服务使用的 API 格式。可选项如下：
OpenAI Chat Completions 格式 ：兼容 OpenAI /v1/chat/completions 接口规范，适用于大多数 OpenAI 兼容模型服务。常见兼容服务包括 OpenAI、DeepSeek、Kimi、GLM、OpenRouter、部分 Ollama/OpenAI 兼容代理等。
Anthropic Messages 格式 ：兼容 Anthropic /v1/messages 接口规范，适用于 Claude 系列及兼容 Anthropic Messages API 的模型服务。常见兼容服务包括 Anthropic Claude、部分 Claude API 代理服务等。
|
自定义请求地址
|
填写模型服务的请求地址。你可以根据服务商提供的地址格式选择以下方式：
方式一 ：打开 完整 URL 开关，然后填写完整请求地址。
方式二 ：关闭 完整 URL 开关，然后填写基础地址，由 TRAE 按所选 API 格式拼接请求路径。
|
模型 ID | 
 输入模型服务商提供的模型 ID。根据模型服务商提供的 ID 填写即可。 |
模型展示名称 |

API 密钥 | 
 填写调用该模型所需的 API 密钥，用于鉴权。 |

模型系列
|
TRAE 为特定模型系列优化了 Prompt、超参配置等，详情参考 模型系列选项详解 。
以下选项 TRAE 个人版和企业版均可用：
GPT-5 系列 ：推荐用于 GPT-5 系列模型。
Gemini-3 系列 ：推荐用于 Gemini-3 系列模型。
DeepSeek-4 系列 ：推荐用于 DeepSeek-4 系列模型。
默认 ：不针对特定模型系列做任何调优，使用 TRAE 通用的 Prompt 模板与超参配置。
以下选项仅 TRAE 企业版可用：
Kimi 系列 ：推荐用于 Kimi-K2、Kimi-K3 系列模型。
GLM-5 系列 ：推荐用于 GLM-5 系列模型。
GPT-6 系列 ：推荐用于 GPT-6 系列模型。
Claude-4 系列 ：推荐用于 Claude-4 系列模型。
|
上下文窗口
|
设置该模型单次请求可接收的最大 Token 数，即 “输入”；以及单次响应可生成的最大 Token 数，即 “输出”。你可以从输入框右侧的预设上下文窗口中选择，也可以手动输入数值。
提示 ：若留空，将使用 TRAE 内置的默认最优值。
|
工具调用轮数 | 
 设置模型在单次任务中可调用工具的最大轮数。数值越高，模型可执行的连续工具操作越多，但耗时和 Token 消耗也可能增加。若留空，将使用 TRAE 内置的默认最优值。 |
支持图片输入 | 
 设置该模型是否可接收图文混合输入。需所选模型本身具备视觉理解能力，否则无法正常识别图片内容。 |
思考模式 | 
 控制模型在回答前是否进行推理。开启后可提升复杂问题的处理质量，但可能增加响应耗时与 Token 消耗。若选择 跟随模型默认配置 ，则沿用模型服务商的默认设置。 |
采样参数
|
控制模型生成回答时的采样策略，影响输出的稳定性、多样性和随机性。
Temperature ：控制输出随机性。数值越高，回答越发散；数值越低，回答越稳定。取值范围：[0, 2]。
Top P ：控制候选词的累计概率范围。数值越高，可选范围越大；数值越低，输出越收敛。取值范围：[0, 1]。
Top K ：控制每一步生成时可参与采样的候选词数量。数值越高，输出越多样；数值越低，输出越集中。取值范围：[1, 100]。
提示 ：若留空，TRAE 将使用模型服务商内置的默认值（一般为默认最优配置）。
|
点击 添加模型 按钮。
TRAE 将调用服务商的接口来检测 API 密钥是否有效：
若连接成功，该模型将被添加到模型列表。
若连接失败，窗口中将展示错误信息和服务商返回的日志，你可以根据这些信息排查问题。
管理自定义模型
添加自定义模型后，你可以在模型列表中编辑、删除、启用或禁用该模型。
操作类型 | 
 描述 |
编辑模型 | 
 点击 编辑 图标，然后修改模型的高级配置。 |
删除模型 | 
 点击 删除 图标，然后在弹窗中二次确认。删除后，当前模型将被从列表里移除，不可被继续使用。 |
启用/禁用模型 | 
 启用后，自定义模型会出现在对话框的模型选择列表中；禁用后，模型将保留在模型管理面板，但不会出现在对话框的模型选择列表中。 |

模型系列选项详解
通过自定义配置添加特定系列的模型时，你可以选择 TRAE 预设的模型系列选项。TRAE 已为这些系列优化了 Prompt、超参等配置，以提升模型性能，详见下表。
选项 | 
 描述 |
GPT-6 系列
|
选择该选项后，TRAE 会按 GPT-6 的协议要求调整请求字段，并应用推荐超参和专属 Prompt 模板，具体包括：
协议自动适配 ：GPT-6 协议要求使用 MaxCompletionTokens 字段传递最大生成长度（默认配置使用 MaxTokens ），选择该系列后 TRAE 会自动完成协议字段转换，避免因协议不匹配导致的请求失败。
专属 Prompt 优化 ：内置一套独立的 Prompt Engineering 模板，针对 GPT-6 的指令遵循特性做了调优，相比默认配置，在工具调用、代码生成等任务上效果更佳。
|
GPT-5 系列
|
选择该选项后，TRAE 会按 GPT-5 的协议要求调整请求字段，并应用推荐超参和专属 Prompt 模板，具体包括：
协议自动适配 ：GPT-5 协议要求使用 MaxCompletionTokens 字段传递最大生成长度（默认配置使用 MaxTokens ），选择该系列后 TRAE 会自动完成协议字段转换，避免因协议不匹配导致的请求失败。
超参预置为推荐值 ： Temperature 固定为 1 （GPT-5 仅支持该取值）。
专属 Prompt 优化 ：内置一套独立的 Prompt Engineering 模板，针对 GPT-5 的指令遵循特性做了调优，相比默认配置，在工具调用、代码生成等任务上效果更佳。
|
Gemini-3 系列
|
选择该选项后，TRAE 会按 Gemini-3 的推理协议解析推理内容，并应用推荐超参，具体包括：
Reasoning 协议自动适配 ：Gemini-3 系列模型的推理内容需通过 thought_signature 字段回传（默认配置通过 reasoning_content 字段回传）。选择该选项后，TRAE 会自动按 Gemini-3 协议解析推理过程，确保推理链路被正确展示与利用。
超参预置为推荐值 ： Temperature 设为 0.1 。
|
DeepSeek-4 系列
|
选择该选项后，TRAE 会为 DeepSeek-4 预设思考模式和推荐超参，具体包括：
默认开启 Thinking 模式 ：自动启用深度思考，无需额外配置即可获得更强的推理能力，适合复杂代码生成与逻辑分析。
超参预置为推荐值 ： Temperature 设为 0.1 。
|
Kimi 系列
提示 ：仅企业版可用
|
选择该选项后，TRAE 会自动为 Kimi 系列模型启用深度思考 Thinking 模式，无需额外配置即可获得更强的推理能力，适合复杂代码生成与逻辑分析。
|
GLM-5 系列
提示 ：仅企业版可用
|
选择该选项后，TRAE 会自动为 GLM-5 系列模型启用深度思考 Thinking 模式，无需额外配置即可获得更强的推理能力，适合复杂代码生成与逻辑分析。
|
Claude-4 系列
提示 ：仅企业版可用
|
选择该选项后，TRAE 会为 Claude-4 预设思考模式，并启用面向智能体任务的专项 Prompt Engineering，具体包括：
默认开启 Thinking 模式 ：自动启用深度思考，无需额外配置即可获得更强的推理能力，适合复杂代码生成与逻辑分析。
使用专项 Agent PE ：针对 Claude 优化了计划生成、任务拆解、子智能体协作、后台任务管理以及检索工具契约。
