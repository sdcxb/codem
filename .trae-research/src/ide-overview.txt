TRAE
深度融合 AI 能力的集成开发环境，提供从代码编写、项目理解、调试运行到变更管理的完整体验，适合需要完整开发环境的工程师。
双形态
提供 Agent 窗口与 IDE 窗口，面向不同开发方式，实时同步任务数据和配置。
AI 编程能力
提供智能体、自定义模型、代码补全，上下文引用等 AI 编程核心能力。
开发工具链
支持代码编辑、调试运行、Git 管理、智能代码审查、插件扩展等能力。

TRAE Plugin
把以智能代码补全为代表的 AI 编程能力，无缝融入你已经熟悉的 IDE。不更换工作环境，也能获得 AI 辅助，适合已习惯使用某个固定 IDE 的开发者。
广泛 IDE 与语言支持
覆盖 VS Code、JetBrains 系列、Android Studio，以及前端、后端、移动端等常见语言。
即装即用
在已使用习惯的 IDE 中，装上 TRAE Plugin，就能为你熟悉的开发环境接入 AI 编程能力。
可扩展性
集智能体、代码补全、MCP、自定义规则等能力于一体，让 TRAE Plugin 灵活适配你的使用场景。

 查看文档
TRAE CLI
运行在终端和研发工作流中的 Code Agent。在终端输入自然语言指令，让它完成代码编写、测试调试和 Git 操作等复杂任务，适合偏好在终端工作或希望自动化开发的工程师。
自动化
编写与修改代码，理解业务逻辑，运行测试并修复失败用例，自动处理 Git 工作流。
CI/CD 集成
支持非交互模式，可嵌入自动化脚本或持续集成流水线中。
可拓展性
通过 MCP 集成第三方工具与服务，也支持配置自定义智能体、命令等。

TRAE 企业版
面向企业和团队的专属版本，既能让成员在各自习惯的 TRAE 客户端中使用 AI 编程能力，也能让管理员统一管理席位、用量、数据与安全策略等。适合需要统一治理 AI Coding 使用的企业和团队。
企业管理
管理员可以管理人员与席位，设置用量限额，并通过数据面板洞察团队的 AI 使用情况。
企业配置
支持企业知识库、企业智能体、企业内置模型，提供专属域名、网络代理等数十种企业安全能力。
开放平台
通过 OpenAPI 接入内部系统，用于成员管理、数据同步和审计追踪。
