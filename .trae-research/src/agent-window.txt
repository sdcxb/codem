 Agent 窗口快速开始
 复制页面
Agent 窗口是 TRAE 提供的 AI 原生工作台，旨在为用户提供统一、高效、可定制的 AI 协作体验，覆盖从专业开发到日常办公的各类场景。
Agent 窗口与 IDE 窗口之间的协同
Agent 窗口与 IDE 窗口之间会自动同步以下内容：
本地任务的对话流与最终产物；
云端与工作树任务的进度；
MCP、技能、规则、记忆、工具与扩展、IDE 设置等配置。
打开 Agent 窗口
在 IDE 窗口右上角，点击 Agent 按钮，即可打开 Agent 窗口。
发送消息
在右侧面板中部的对话输入框中，你可以向 AI 发送消息。AI 会生成一个任务，处理消息中的指令。你后续可以在该任务的对话中与 AI 连续沟通。

管理任务
你可以对任务进行置顶、重命名、删除等操作。
通过以下任一方式打开任务的操作菜单：
在左侧任务栏中，将鼠标悬浮至目标任务，然后点击任务条目右侧的 更多操作 图标。
在对话面板顶部，点击任务名称右侧的 更多操作 图标。
从菜单中选择所需操作，包括：
置顶或取消置顶任务；
查看任务相关的文件（列表视图或树状视图），以及在任务中新建文件或文件夹；
重命名任务；
分享任务中的对话；
删除任务。
全局搜索
你可以通过关键词进行跨模式全局搜索，快速查找目标任务或任务中的 Query。
在界面左上角，点击搜索图标。
在弹出的搜索框中输入关键词，查找目标任务或 Query。
关于云端智能体
Agent 窗口提供的云端智能体（Cloud Agent）能让你在云端环境中执行代码分析、运行和调试等任务。该环境提供了统一的运行时与依赖管理，确保所有代码都在一个稳定且隔离的远程环境中完成。这可以有效避免本地环境差异带来的兼容性或性能问题，让你能更专注于任务本身，而不必为环境配置或设备限制分心。
