全新升级，全面开放！一图读懂 SOLO 正式版
 TRAE.ai
凌敏
2025-11-17 北京
本文字数：800 字 
 阅读完需：约 3 分钟
11 月 12 日，TRAE 国际版的 SOLO 模式正式版发布。 全新升级、全面开放的 SOLO 模式，作为 The Responsive Coding Agent 是一种高度自动化的开发方式：它以 AI 为主导，可理解目标、承接上下文并调度工具，独立推进各阶段开发任务。
SOLO 正式版：The Responsive Coding Agent
 实时有感知 / Responsive Review
全新开发空间设计，三栏布局让 AI 开发更清晰、高效：智能摘要 + 任务拆解 + 会话跳转，实时掌握开发进程。
新增 DiffView 工具，清晰展示 AI 所有代码变更：集中展示代码变更、实时代码审查反馈，确认变更才生效。
随时可掌控 / Responsive Context
新增内置智能体 SOLO Coder + Plan，计划确认再开发：集成更多工具，与智能体协同随时反馈、有效沟通。
上下文管理功能上线：进度展示、上下文压缩。节省成本，保留价值内容、不让模型失焦。
多任务并行 / Responsive Multi-Tasking
Coding Agent 按需选择，适配不同开发需求：
 原 SOLO Builder 支持端到端生成，快速验证上线小型项目；
 全新 SOLO Coder 处理复杂项目迭代、重构，可自动调用不同智能体。
支持多任务并行，多线程工作无需等待：新增多任务列表，支持同时开发不同功能模块。
三大场景：用 SOLO 模式快速响应
 项目理解：快速理解新项目/复杂代码库
打开新项目 @SOLO Coder，生成介绍、总结规范、解答技术问题。
SOLO Coder 按照需求生成项目理解文档 
 需求迭代：根据产品需求快速迭代功能
@SOLO Coder 开启 Plan 生成计划，确认后开发。SOLO Coder 自动调用不同智能体完成任务，开启新任务 @SOLO Coder，并行开发多模块，进度清晰可见，对话结束后统一查看代码变更，明确范围。
先生成再调优计划，以确保代码生成符合需求 
 Bugfix：紧急修复不符合预期的 Bug
@SOLO Coder 描述 Bug 表现，开启 Plan 生成修复计划，确认后执行，SOLO Coder 快速定位 Bug 代码，完成修复。
将项目启动报错信息发送给 AI 进行修复
*SOLO 模式当前仅面向 TRAE 国际版，中国版 SOLO 模式敬请期待。
